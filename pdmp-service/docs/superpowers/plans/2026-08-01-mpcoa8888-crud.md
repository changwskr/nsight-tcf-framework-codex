# mpcoa8888 CRUD Service Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `pdmp-service`에 `TB_CR_AH_SALES_TIP_RACT`를 조회·등록·수정·물리 삭제하는 독립 프로그램 `mpcoa8888`을 추가한다.

**Architecture:** 기존 `mpcoa9999`의 표준 전문과 Controller-Service-DAO-MyBatis 흐름을 유지하되 모든 파일과 SQL ID를 `mpcoa8888` 계약으로 분리한다. Service가 입력 정규화, 페이징, 업무 오류 및 트랜잭션을 담당하고 MyBatis가 Oracle/H2 호환 SQL을 실행한다. `/api/mp/co/a/8888/**`만 기존 JWT 인증 체계의 인증 대상으로 제한한다.

**Tech Stack:** Java 21, Spring Boot 3.5, Spring MVC, Spring Security, Spring Transaction, MyBatis 3, H2 Oracle mode, JUnit 5, Mockito, Gradle

## Global Constraints

- 작업 범위는 `pdmp-service`뿐이며 `pdmp-ui`와 다른 프로젝트를 수정하지 않는다.
- 기존 `mpcoa9999` 소스와 API 계약을 변경하지 않는다.
- API는 `POST`, `StandardRequestDto`, `StandardResponseDto`, `@TcfTransaction`을 사용한다.
- 복합키는 `TRT_BRC`, `TRTMN_ENO`, `SALZ_TIP_KDC`, `BAS_DT`이며 수정할 수 없다.
- 목록 검색은 `SALZ_TIP_KDC` 완전 일치, 정렬은 `BAS_DT DESC`, `TRT_BRC`, `TRTMN_ENO` 순이다.
- 페이지 기본값은 1/20이고 페이지 크기 상한은 100이다.
- 등록·수정·삭제는 `@Transactional(timeout = 4)`를 사용하며 삭제는 물리 삭제다.
- 없는 상세·수정·삭제 대상은 `MP0404`, 중복 등록은 `MP0409`로 처리한다.
- 운영 코드보다 실패하는 테스트를 먼저 작성한다.
