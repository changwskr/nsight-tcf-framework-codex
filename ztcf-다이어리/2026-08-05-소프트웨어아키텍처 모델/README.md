## 한눈에 보는 흐름

```text
이해관계자 선별
  → 컨텍스트/바운더리 · 상위 기능(유즈케이스)
  → 품질속성 도출 · 품질속성 시나리오 (비기능 모델링)
  → 아키텍처 설계전략 (패턴/솔루션 매핑)
  → Viewpoint별 뷰 작성 (Runtime / Allocation / Module)
  → 아키텍처 평가 (대안 비교 · 필요 시 프로토타입)
```

**핵심 한 줄:** 아키텍처 설계 = **비기능(품질속성)을 해결하는 구조가 그림에 보이게** 만드는 일.
