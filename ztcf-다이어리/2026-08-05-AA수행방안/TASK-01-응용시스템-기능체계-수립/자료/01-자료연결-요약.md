# 자료연결 요약 — 응용시스템 기능체계 수립

## TASK-01과 자료의 연결

기능체계 수립은 EA **AV1(구성/정의)·AV3(기능분할)** 을 만드는 일이다. TCF 다이어리에서는 동일 문제를 **업무 도메인 분할(APP-01)** 과 **거버넌스 승인(GOV-01)** 으로 다룬다.

| AA 산출물 | TCF 대응 |
|-----------|----------|
| AV1 응용시스템 정의 | 도메인·WAR/모듈 경계 목록 |
| AV3 1·2차 기능 | 도메인 내 기능 계층·추적 ID |
| SRM/TRM 참조 | 공통서비스·기술표준 준수 |

**실무 팁:** PGAMS 샘플의 입학/학적/성적을 APP-01 도메인 단위로 먼저 나눈 뒤 AV3를 채운다.
