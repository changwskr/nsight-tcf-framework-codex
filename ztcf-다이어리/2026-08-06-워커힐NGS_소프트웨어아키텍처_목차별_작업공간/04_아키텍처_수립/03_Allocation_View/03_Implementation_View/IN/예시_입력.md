# 예시 입력 — Implementation View 구현 구조 조사

```text
src/common
src/{Ear}
src/{Ear}/APP-INF
src/{Ear}/META-INF
src/{Ear}/{Ejb}/{subsystem}/{service}/biz
```

| 변수 | 예시 |
|---|---|
| {Ear} | FrontOffice 또는 BackOffice |
| {Ejb} | {subsystem}Ejb |
| {WebApp} | {subsystem}WebApp |
| Java Base Package | com.walkerhill.{subsystem} |

## 확인할 파일
- EAR/WAR/JAR 배포 디스크립터
- XSQL·설정·라이브러리 경로
- 빌드 스크립트와 산출물명
