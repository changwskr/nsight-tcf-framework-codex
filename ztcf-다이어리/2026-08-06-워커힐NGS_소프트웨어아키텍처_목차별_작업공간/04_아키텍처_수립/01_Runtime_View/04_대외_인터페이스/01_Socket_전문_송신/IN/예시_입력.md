# 예시 입력 — Socket 전문 송신 계약 초안

| 항목 | 예시 값 |
|---|---|
| 송신 시스템 | NGS Interface System |
| 수신 시스템 | PMS/POS/VAN 중 대상 확정 |
| 프로토콜 | Socket 또는 FTP/NFS |
| 문자셋 | 시스템별 협의 |
| 식별자 | interfaceId, messageId, businessDate |
| Timeout | 미확정 |
| 재시도 | 미확정 |
| 중복판정키 | messageId + businessDate 후보 |

## 오류 후보
- 연결 실패
- 전문 길이/형식 오류
- 업무 거절
- 응답 Timeout
- 중복 수신
