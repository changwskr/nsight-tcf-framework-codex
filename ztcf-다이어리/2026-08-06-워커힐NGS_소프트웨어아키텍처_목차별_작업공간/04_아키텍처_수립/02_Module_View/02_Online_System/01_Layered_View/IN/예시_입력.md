# 예시 입력 — 계층별 프로그램 후보

| 계층 | 원문 구성요소 | 현재 후보 |
|---|---|---|
| Presentation | HTML/JSP | 화면·리포트 |
| Command | Front Controller, CommandProcessor | 요청 검증·호출·응답 변환 |
| Business | Service Facade(EJB), Business Unit(POJO) | 유스케이스·업무 로직 |
| Infrastructure | SQL Manager, DAO, 외부 솔루션 | DB·외부 연계 |

## 검토 대상
- Transaction-Id와 Service Facade 메서드 대응
- 인접 계층 호출 원칙
- DTO/VO 전달 경계
