# 예시 입력 — II.2.1 비즈니스 제약사항

## 수집 대상
- 제약 원문·근거
- 영향 대상
- 강제/협의/가정 구분
- 위험·완화책
- 유효기간·재검토 조건

## 사실/가정 구분
| 구분 | 내용 | 근거/담당자 |
|---|---|---|
| 원문 사실 | 비즈니스 제약사항에 필요한 입력, 분석·설계 활동, 산출물과 검증 기준을 원문 아키텍처 정의 체계에 맞춰 수행한다. | 원문 논리 페이지 15 |
| 현재 확인값 | 미확인 | 담당자 확인 필요 |
| 가정 | 예시 가정 | 승인 전 사용 금지 |
| 미결정 | 결정이 필요한 항목 | ADR 등록 |
