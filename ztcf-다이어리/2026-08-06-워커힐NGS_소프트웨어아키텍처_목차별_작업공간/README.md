# 워커힐 NGS 소프트웨어 아키텍처 정의서 — 목차별 작업공간

## 1. 도입 전 안내말

이 패키지는 **「워커힐 NGS(차세대 시스템) 소프트웨어 아키텍처 정의서 v1.0」**의 목차를 실행 가능한 작업구조로 재구성한 것이다.

각 목차 디렉터리는 다음 구조를 갖는다.

```text
{목차 디렉터리}/
├─ TASK.md              # 해야 되는 일, 입력, 산출물, RACI, 품질 Gate
├─ IN/
│  ├─ README.md         # 입력자료 보관 규칙
│  └─ 예시_입력.md      # 목차별 입력 예시
└─ OUT/
   ├─ README.md         # 산출물 보관 규칙
   └─ 예시_산출물.md    # 목차별 결과 예시
```

## 3. 사용 절차

```text
1. 해당 목차의 TASK.md를 읽는다.
2. 원천자료를 IN에 추가한다.
3. 분석·설계·검토를 수행한다.
4. 산출물과 증적을 OUT에 작성한다.
5. TASK.md의 품질 Gate를 확인한다.
6. 상위 목차의 통합 인덱스와 Risk/Gap을 갱신한다.
```

## 4. 원문과 현재 아키텍처의 구분

원문에는 Java 1.5, J2EE 1.4, JEUS 5, NEXCORE 4.0, Apache MINA 2.0, Informix v10, ActiveX/IE6, EAR/EJB/WAR 등 2008년 기준 기술이 포함되어 있다. 이 패키지는 해당 내용을 **원문 기준선**으로 보존한다. 현재 적용 여부, 지원 종료, 현대화 목표는 별도 현행조사와 ADR로 결정해야 한다.
