# 예시 입력 — I.2 프로젝트 개요

## 수집 대상
- 사업 비전
- 정량·정성 목표
- 이해관계자 기대효과
- 성공지표(KPI)
- 범위·제외범위

## 사실/가정 구분
| 구분 | 내용 | 근거/담당자 |
|---|---|---|
| 원문 사실 | 고객가치 창출과 수익 극대화를 지원하는 차세대 시스템의 비전, 단계별 범위, TO-BE 모델을 확정한다. | 원문 논리 페이지 2 |
| 현재 확인값 | 미확인 | 담당자 확인 필요 |
| 가정 | 예시 가정 | 승인 전 사용 금지 |
| 미결정 | 결정이 필요한 항목 | ADR 등록 |
