# 예시 입력 — I.2.2 단계별 구축범위

## 수집 대상
- 단계별 업무범위
- 선행·후행 관계
- 병행운영 대상
- 전환·데이터 이관 계획
- 단계별 완료 기준

## 사실/가정 구분
| 구분 | 내용 | 근거/담당자 |
|---|---|---|
| 원문 사실 | 단계별 구축범위에 필요한 입력, 분석·설계 활동, 산출물과 검증 기준을 원문 아키텍처 정의 체계에 맞춰 수행한다. | 원문 논리 페이지 2 |
| 현재 확인값 | 미확인 | 담당자 확인 필요 |
| 가정 | 예시 가정 | 승인 전 사용 금지 |
| 미결정 | 결정이 필요한 항목 | ADR 등록 |
