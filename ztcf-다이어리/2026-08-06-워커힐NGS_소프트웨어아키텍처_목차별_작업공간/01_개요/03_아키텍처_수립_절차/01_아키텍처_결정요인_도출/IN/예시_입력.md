# 예시 입력 — I.3.1 아키텍처 결정요인 도출

## 수집 대상
- 단계별 입력·출력
- 수행 역할·RACI
- 검토·승인 Gate
- 평가 기준
- 추적성·변경관리

## 사실/가정 구분
| 구분 | 내용 | 근거/담당자 |
|---|---|---|
| 원문 사실 | 아키텍처 결정요인 도출에 필요한 입력, 분석·설계 활동, 산출물과 검증 기준을 원문 아키텍처 정의 체계에 맞춰 수행한다. | 원문 논리 페이지 4 |
| 현재 확인값 | 미확인 | 담당자 확인 필요 |
| 가정 | 예시 가정 | 승인 전 사용 금지 |
| 미결정 | 결정이 필요한 항목 | ADR 등록 |
