## 2. 비기능 요구사항 Baseline (설계 단계 필수)

| ID | NFR | 목표 값 | 검증 방법 |
| --- | --- | --- | --- |
| NFR-01 | 응답시간·TPS | 미확정 (수치 추후) | 표준 POST 호출 측정 / 성능 시험(해당 시) |
| NFR-02 | Timeout·재시도 | 미확정 (초·정책 추후) | Timeout 정책 등록·로그 `TIMEOUT_POLICY` / 초과 시나리오 |
| NFR-03 | (참고) SQL 성능 | M1 사람 유지 | 실행·인덱스 검토 — AA 승인 |
| NFR-04 | (참고) 업무 Rule | M1 사람 유지 | Rule 코드·테스트 |

설계 단계 **필수 확정 대상** = NFR-01, NFR-02.  
값은 나중에 채워도 되지만, **란과 검증 방법은 Baseline에 존재**해야 한다.
