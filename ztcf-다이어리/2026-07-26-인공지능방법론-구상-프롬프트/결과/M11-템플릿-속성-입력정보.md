## 1. 공통 메타정보 (전부 필수)

Artifact ID, 프로젝트 ID, 업무코드, 도메인, 버전, 상태,  
작성자, 검토자, 승인자, 작성일, 기준 소스 버전,  
선행/후속 Artifact, 연결 ServiceId, 변경사유, 승인상태,  
생성 방식, 검증 증적, 폐기 여부

## 2. 템플릿별 필수 필드

### 화면

화면ID·명, 업무코드·도메인, 메뉴·권한, UI 구성요소, 입출력 필드,  
이벤트, 호출 ServiceId, Validation, 정상·오류 처리, 개인정보 표시·마스킹

### 거래

ServiceId, 거래코드, 처리유형, Endpoint, Request·Response,  
인증·권한, Timeout, 멱등성, Handler, 트랜잭션, 오류코드,  
로그·감사, 호출 프로그램·SQL

### 프로그램

클래스·패키지, 계층, 책임, 입력·출력, 호출 대상, 금지 호출,  
트랜잭션, 예외, 테스트, 변경 영향

### 데이터·SQL

테이블·컬럼, PK·인덱스, 데이터 소유권, SQL ID, Mapper Namespace,  
조회조건, 예상 건수, 성능기준, 개인정보, 변경 영향

## 3. 필수·선택·조건부

| 구분 | 규칙 |
| --- | --- |
| 필수 | 위 목록 + 공통 메타 |
| 선택 | 템플릿별 부가 설명·다이어그램 |
| 조건부 | 연계 IF(1차 해당 시), Gateway(제외), 개인정보 마스킹(해당 컬럼 있을 때) |

값이 없으면 공란 금지 → `미확정` 또는 `해당없음` 명시.

## 4. 템플릿 간 참조키

| From | Key | To |
| --- | --- | --- |
| 화면 이벤트 | ServiceId | 거래 |
| 거래 | Handler / SQL ID | 프로그램 / SQL |
| 프로그램 | 패키지·클래스 | 소스 (SoT) |
| SQL | 테이블명 | 데이터·소유권 (M6) |
| 공통 | Artifact ID | 선행/후속 Artifact |

## 5. 입력 검증규칙 (최소)

1. ServiceId 형식: `{업무코드}.{Domain}.{action}`  
2. 업무코드·도메인은 M5 매핑과 일치  
3. 테이블 소유권은 M6과 일치  
4. Timeout 란은 거래 템플릿에 존재 (수치 미확정 허용 — M7)  
5. 승인상태=승인 전 코드 생성 금지 (M4)
