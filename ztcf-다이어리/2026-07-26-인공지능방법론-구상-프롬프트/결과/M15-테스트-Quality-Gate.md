## 1. 자동 vs 수동 Gate

| 수준 | 내용 | 방식 |
| --- | --- | --- |
| ① 컴파일 | Gradle compile | **자동** |
| ② 단위테스트 | `:test` (존재 시) | **자동** |
| ③ 구조·명명 | 패키지·계층·금지패턴·ServiceId/Mapper 명명 | **자동 (상한)** |
| ④ DB·거래 통합 | POST /online, DB 결과 | **수동** (필수 완료조건) |
| ⑤ 배포·운영 | verify-deploy, OM, 로그 | **수동** |

## 2. Quality Gate 정의서

### 모델 Gate (자동·반자동)

필수값, 중복 ID, 참조 무결성, 소유권(M6), 미승인 항목(M4)

### 코드 Gate (자동 ≤③)

Gradle Build, 패키지 구조, 계층 의존성, 금지 Import,  
ServiceId 중복, Handler 등록 가능성, Mapper↔XML 일치, SQL ID

### 정합성 Gate (수동 체크리스트)

화면이벤트 ↔ ServiceId ↔ Handler ↔ … ↔ SQL·Table  
↔ OM ↔ Timeout ↔ 테스트 ↔ 거래로그

### 런타임 Gate (수동, 완료 필수)

bootRun, 표준 POST, 정상/오류, Timeout 시나리오(수치 미확정 시 스킵 표기),  
Rollback, 로그 GUID 추적, DB 결과

### 증적 Gate (수동, AA A)

Commit ID, 모델/문서 버전, 빌드·테스트 결과, 요청·응답, OM(해당 시)

## 3. 완료 증적 기준 (CRUD 시범)
