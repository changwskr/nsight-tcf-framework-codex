## 1. 공식 SoT 지정안

| 순위 | SoT | 상태 |
| ---: | --- | --- |
| 1 | 현재 작업 Branch의 실제 소스 | **승인 기준 = 현행 구현** |

충돌 시: 문서·설계서·일반 권고보다 **소스가 우선**.

## 2. 기준자료 목록·상태

| # | 자료 | 상태 | 1차 사용 |
| --- | --- | --- | --- |
| ① | 실제 NSIGHT-TCF 소스 | 현행 구현 / 승인 기준 | **예** |
| ② | 기존 정상 업무 모듈 | *(①에 포함되는 경로로만 참조)* | 소스 경로로만 |
| ③ | 화면정의서 | Gap | 아니오 |
| ④ | 테이블·컬럼정의서 | Gap | 아니오 |
| ⑤ | 거래·프로그램 설계서 | Gap | 아니오 |
| ⑥ | API·인터페이스 정의서 | Gap | 아니오 |
| ⑦ | 운영·OM 기준정보 | Gap | 아니오 |
| ⑧ | 테스트케이스·실행로그 | Gap | 아니오 |

## 3. 자료 우선순위

```text
1. 현재 Branch 소스 (av-service, tcf-core, tcf-web, tcf-ui, settings/build, yml)
2. (없음 — 2순위 SoT 미지정)
3. 일반 기술지식·설계 권고 — 참고만, 사실로 쓰지 않음
```

## 4. 소스·문서 Gap

| Gap | 의미 | 방법론 대응 |
| --- | --- | --- |
| 화면·테이블·거래 설계서 부재 | ③④⑤ 미사용 | 소스에서 역추출하거나 템플릿을 새로 정의(M10~) |
| OM Catalog | ⑦ 미사용, AV 등록 여부 소스 재확인 필요 | 완료 증적 Gap (M15) |
| CUD 미구현 | M2 To-Be | 현재 구현 ≠ 목표 표준 |
| 테스트·실행로그 | ⑧ 미사용 | Gate 자동화는 이후 단계 |
| 배치·Gateway | M0 제외 | 기준자료에서도 제외 |
