# 방법론 결과물 저장소

여기에 **단계별 확정 마크다운**을 쌓는다.  
프롬프트 파일(`../M0`~`../M18`)은 “질문”이고, 이 폴더는 “답의 공식 기록”이다.

## 파일 규칙

| 파일 | 내용 |
| --- | --- |
| `M0-방법론-수립범위.md` ~ `M17-선도개발-확산.md` | 해당 단계 확정표 + 산출물 본문 |
| `00-NSIGHT-TCF-AI-LLM-SI-개발방법론.md` | M18에서 통합한 최종 기준서 |

## 단계 확정표 (필수 머리)

각 `결과/M*.md` 상단에 아래 표를 둔다.

| 구분 | 내용 |
| --- | --- |
| 단계 | M0 … |
| 사용자 답변 | 원문 요약 |
| 확정사항 | 이후 단계에서 공식 기준으로 쓸 내용 |
| 미확정사항 | 추가 판단·자료 확인 필요 |
| 설계 영향 | 이후 아키텍처·템플릿·코드에 미치는 영향 |
| 산출물 반영 | 어느 설계서·모델에 반영할지 |
| 다음 단계 | 다음 M 번호 |

## 작성 원칙

1. 이전 단계 결과를 덮어쓰지 말고, 변경 시 영향 범위를 명시한다.
2. 저장소에서 확인되지 않은 값은 `미확정` / `설계 예시`로 남긴다.
3. “알아서”, “적절히”, “상황에 맞게” 같은 표현을 쓰지 않는다.
4. M18 통합 전에는 최종 방법론 본문을 미리 쓰지 않는다.
