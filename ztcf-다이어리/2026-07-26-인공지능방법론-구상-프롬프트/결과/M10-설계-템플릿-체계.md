## 1. 표준 템플릿 카탈로그

| 분류 | 템플릿 | 상태 | 1차 작성 |
| --- | --- | --- | --- |
| 프로젝트 | 프로젝트 정의·범위 | 유지 | 수동/골격 |
| 요구사항 | 요구사항·RTM | 유지·보완 | 수동 (M7 연결) |
| 업무 | 업무기능·도메인 | 유지 | 수동 (M5) |
| 화면 | 화면설계서 | 유지·보완 | **AI 초안** |
| 이벤트 | 화면 이벤트 | 유지·보완 | **AI 초안** (화면에 통합 가능) |
| 데이터 | 테이블·컬럼 | 유지·보완 | **AI 초안** |
| 거래 | 거래설계서 | 유지·보완 | **AI 초안** |
| 전문 | Req/Response | 유지·보완 | **AI 초안** (거래에 통합 가능) |
| 식별자 | ServiceId·거래코드 | 유지 | 수동+AI 초안 |
| 프로그램 | Handler~Mapper 설계 | 유지·보완 | **AI 초안** |
| DTO | DTO 정의 | 유지 | **AI 초안** (프로그램에 포함 가능) |
| 규칙 | Rule·Validation | 유지 | 사람 주도 (M1) + AI 골격 |
| SQL | Mapper·SQL | 유지·보완 | **AI 초안** / 성능은 사람 |
| 연계 | 내부·외부 IF | 유지 | 1차 해당 없음(보류) |
| 보안 | 인증·권한·개인정보·감사 | 유지 | 골격/미확정 |
| 운영 | OM·Timeout·거래통제 | 유지·보완 | 초안 가능, AA 승인 |
| 테스트 | 단위·통합·거래 | 유지 | 골격 |
| 배포 | 환경·배포·롤백 | 유지 | 골격 (Gateway/배치 제외) |
| 추적성 | 화면–ServiceId–프로그램–SQL–DB | 유지·보완 | **AI 초안** |
| 변경 | ADR·영향·호환·폐기 | 유지 | 수동 |

## 2. AI 자동 초안 vs 사람 작성 (1차)

| AI 자동 초안 (핵심) | 사람 작성·승인 중심 |
| --- | --- |
| 화면, 거래, 프로그램, 테이블, SQL, 추적성 | Rule 본문, SQL 성능·인덱스, Timeout 수치, Baseline 승인(AA) |
| (포함 가능) 이벤트·전문·DTO | 프로젝트/요구/연계/변경, 보안·개인정보 상세 |

## 3. 템플릿 선후관계 (CRUD 1차)

```text
요구·도메인·데이터소유권 (M5~M7)
  → 화면·이벤트
  → ServiceId·거래·전문
  → 프로그램·DTO·Rule
  → SQL·테이블
  → 추적성
  → OM·Timeout
  → Baseline 승인 (M4)
  → 코드 생성 (이후)
```

## 4. 버전관리 기준 (최소)

- Artifact에 버전·상태·기준 소스 버전 기록 (상세 필드는 M11)
- SoT는 소스(M3). 템플릿과 소스 Drift 시 소스가 이김
- 재생성 시 사람 작성 영역 덮어쓰기 금지 (M13에서 상세)
