## 1. 시범 적용 범위

| 항목 | 확정 |
| --- | --- |
| 개발 단위 | ② CRUD 거래 한 세트 |
| 업무코드 | `AV` |
| 모듈 | `av-service` |
| 도메인 | Sample *(설계 예시 명칭, 패키지 `...av`)* |
| 테이블 | `AV_SAMPLE` (1) |
| 화면 | 1개 |
| 거래 | 4건 — inquiry / create / update / delete |
| 채널 | 온라인 only |
| 개발유형 | 기존 업무 모듈에 CUD 보강 (목표). 조회는 현행 구현 활용 |

## 2. 적용 대상 인벤토리

| 구분 | 현재 구현 (As-Is) | 목표 (To-Be) |
| --- | --- | --- |
| ServiceId | `AV.Sample.inquiry` | + create / update / delete *(명칭 미확정)* |
| Handler~Mapper | 조회 경로 존재 | CUD 계층 추가 |
| UI | `tcf-ui` `av/sample-list.html` 등 | CUD 이벤트 보강 *(상세 미확정)* |
| OM Catalog | 미확인/미등록 가능 | CRUD 4건 등록 목표 |
| 외부 연계 | 0 | 0 (1차) |

## 3. 개발유형 분류표

| 유형 | 1차 해당 |
| --- | --- |
| 화면·테이블 기반 CRUD | **예 (중심)** |
| 신규 업무 WAR | 아니오 (보류) |
| 기존 모듈 개선 | **예** (CUD 보강) |
| 타 WAR·외부 연계 | 아니오 (보류) |
| 배치·파일 | 아니오 (제외) |
| Gateway 신규 라우팅 | 아니오 (제외) |
