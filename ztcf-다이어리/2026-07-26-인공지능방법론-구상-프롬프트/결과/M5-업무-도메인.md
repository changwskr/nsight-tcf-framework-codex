## 1. 도메인 분할 기준

**기존 WAR(업무 모듈) 기준.**  
화면·테이블만으로 도메인을 결정하지 않는다.

도메인 책임 경계(함께 변경되는 것):

```text
업무 용어 + 업무 규칙 + ServiceId
+ Handler·Facade·Service·Rule
+ 데이터 소유권 + 권한·감사 + 담당 조직
```

1차에서는 WAR 경계로 잠그고, 내부 규칙은 M6·이후에서 보강한다.

| --- | --- | --- | --- | --- |
| AV | `av-service` | Sample | `AV.Sample.*` | `com.nh.nsight.marketing.av` |

## 3. 도메인 인벤토리 (시범)

| 항목 | 내용 |
| --- | --- |
| 도메인명 | Sample |
| 유스케이스 | Sample CRUD (inquiry/create/update/delete) |
| 핵심 용어 | Sample *(상세 용어사전 미확정)* |
| 변경 책임 | AA 승인 하 업무 개발자 (M4) |
| 타 도메인 관계 | 1차 없음 (타 WAR 연계 보류 — M0/M2) |

## 4. Context Map (1차)

```text
[AV / Sample] ──(없음)── 타 WAR
         │
         └── 소유 테이블: AV_SAMPLE (M6에서 소유권 확정)
```
