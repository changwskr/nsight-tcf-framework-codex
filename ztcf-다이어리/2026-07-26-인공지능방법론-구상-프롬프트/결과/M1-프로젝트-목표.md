## 1. 현행 문제정의서

| 순위 | 문제 | 상태 |
| ---: | --- | --- |
| 1 | 설계서 작성시간 과다 | **확정** |
| 2 | 반복 CRUD 개발비용 | **확정** |
| 3 | (미선정) | **미확정** — 필요 시 M2 이후 보강 |

M0 개정(M2): 시범이 **CRUD 한 세트**로 확대됨. 2순위 “반복 CRUD 비용”은 조회+CUD 골격 반복 비용으로 해석한다.

## 2. AI 도입 목표

| 구분 | 내용 |
| --- | --- |
| 1차 축소 대상 | 설계서 초안·반복 필드 작성 |
| 정성 목표 | 조회 거래 설계서를 템플릿+AI 초안으로 빠르게 채우고, 사람은 승인·보완에 집중 |
| 정량 목표 | 미확정 |

## 3. 사람이 유지해야 할 판단 (최소 3)

1. Timeout·트랜잭션·오류 정책  
2. 업무 규칙·검증 로직  
3. SQL 성능·인덱스  

(데이터 소유권·권한·개인정보·Baseline 승인은 M4·M13에서 재확인)

## 4. 정량·정성 성공기준

| 기준 | 내용 | 상태 |
| --- | --- | --- |
| 정성 (M0 KPI 연결) | 조회 1건을 설계→생성→검증까지 반복 가능한 절차로 문서화 | 확정 |
| 정성 | 설계서 초안 작성 부담이 AI 골격으로 이전됨 | 확정(측정방법은 미확정) |
| 정량 | 설계서 작성 시간 OO% 단축 등 | 미확정 |

## 5. 우선순위 문제목록 (요약)

```text
1순위: 설계서 작성시간 과다     → AI: 문서 초안·반복 필드
2순위: 반복 CRUD(조회) 개발비용 → 이후 단계에서 골격 생성 범위 확정
사람 승인 고정: Timeout/TX/오류, Rule, SQL 성능
```
