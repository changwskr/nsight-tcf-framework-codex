코드 생성부터 시작하지 않는다.  
**프로젝트 기준 → 도메인 → 데이터 → 아키텍처 → 템플릿 → 자동화 → 검증 → 확산** 순서로  
프롬프트를 하나씩 실행하며 방법론 마크다운을 완성한다.

## 사용 방식

```text
1. M00(대화원칙)을 한 번 읽고 고정한다
2. M0 → M18 순서로 파일의 「지금 이 질문을 붙여 넣으세요」를 채팅에 붙인다
3. AI와 질의·확정을 끝낸다 (한 단계 = 질문 1개씩)
4. 단계가 끝나면 결과/Mxx-*.md 로 저장한다
5. 「확정」「진행」「다음」이면 다음 M으로 이동한다
```

최종 통합본은 **M18**에서 `결과/00-NSIGHT-TCF-AI-LLM-SI-개발방법론.md`로 만든다.
