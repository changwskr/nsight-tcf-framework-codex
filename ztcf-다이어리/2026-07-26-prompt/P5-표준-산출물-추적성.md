# P5 — 표준 산출물·추적성 프롬프트

사용: `P0` + `P5` + 업무/거래 식별자 목록

```text
[P5 추적성 산출물 작성 작업]

다음 업무 또는 거래를 기준으로
End-to-End 표준 산출물을 작성하라.

입력정보:

업무코드: {코드}
도메인: {도메인}
화면 목록: {화면}
이벤트 목록: {이벤트}
ServiceId 목록: {ServiceId}
프로그램 목록: {프로그램}
Mapper·SQL 목록: {SQL}
DB 객체 목록: {테이블}
OM 정책: {Timeout·거래통제·감사}
테스트 목록: {테스트}

다음 산출물을 서로 일치하게 작성하라.

1. 화면설계서
2. 화면 이벤트–ServiceId 매트릭스
3. 거래설계서
4. 프로그램설계서
5. DTO 정의서
6. Mapper·SQL 설계서
7. DB 객체 영향표
8. OM Service Catalog 등록표
9. 테스트 추적 매트릭스
10. 운영 로그 추적표
11. 변경 영향 매트릭스

모든 행에는 가능한 범위에서 다음 식별자를 포함하라.

요구사항 ID
화면 ID
이벤트 ID
ServiceId
거래코드
Handler
Facade
Service
Rule
DAO
Mapper
SQL ID
Table
테스트 ID
OM 정책 ID
로그 식별자

실제 소스에서 확인되지 않은 프로그램명과 DB 객체는
'설계 예시'로 표시하라.
```
