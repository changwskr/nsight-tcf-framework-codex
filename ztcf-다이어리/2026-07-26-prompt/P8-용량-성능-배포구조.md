# P8 — 용량·성능·배포구조 프롬프트

사용: `P0` + `P8` + TPS·VM·Pool 입력

```text
[P8 용량·성능 분석 작업]

다음 조건으로 NSIGHT 시스템의 용량과 배포구조를 산정하라.

사용자 수: {명}
동시요청률: {비율}
목표 응답시간: {초}
평시 TPS: {TPS}
피크 TPS: {TPS}
스트레스 TPS: {TPS}
업무 WAR 수: {개}
VM 사양 후보: {CPU/RAM}
VM 대수 후보: {대수}
센터·DR 구조: {구조}
Tomcat 구성: {단일/복수}
JVM Heap: {값 또는 미확정}
Tomcat maxThreads: {값 또는 미확정}
Hikari Pool: {값 또는 미확정}
DB Session 제한: {값}
외부연계 비율: {비율}
평균 SQL 시간: {시간}

다음 시나리오를 비교하라.

- 평시
- 정상 피크
- 설계 피크
- 스트레스
- 응답지연
- 한 VM 장애
- 한 Tomcat 장애
- 한 센터 장애
- DB 지연
- 외부 시스템 지연

산정 범위:

1. 사용자·동시요청·TPS
2. VM CPU·Memory
3. JVM Heap·Metaspace·GC
4. Tomcat Connector Thread
5. 업무 Executor
6. HikariCP
7. DB Session
8. WAR별 자원 격리
9. 단일 Tomcat 다중 WAR 위험
10. 네트워크·L4·Apache·Gateway
11. 세션 또는 JWT 영향
12. DR 수용 가능성

각 계산식, 가정, 안전계수와 근거를 명시하라.

결과물:

- 시나리오별 산정표
- 배포 대안 비교
- 권장 구성
- 위험 임계치
- 성능시험 목표
- 모니터링 항목
- 증설 기준
- 재산정 조건

측정값이 없으면 계산값을 확정치가 아닌 초기 설계값으로 표시하라.
```
