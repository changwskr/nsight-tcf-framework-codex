# 핵심 아키텍처 판단

NSIGHT-TCF에서 가장 효과적인 프롬프트는 다음 다섯 가지를 반드시 포함한다.

```text
첫째, 실제 소스를 먼저 확인한다.

둘째, 확인된 사실과 설계 예시를 분리한다.

셋째, 화면에서 운영로그까지 추적한다.

넷째, 정상뿐 아니라 오류·Timeout·장애를 검증한다.

다섯째, 코드 생성이 아니라 증적 확인을 완료기준으로 삼는다.
```

따라서 프롬프트의 최종 구조는 다음과 같아야 한다.

```text
역할
→ 기준자료
→ 입력정보
→ 선행 분석
→ 설계 판단
→ 구현
→ 테스트
→ 운영 검증
→ 완료 증적
→ 변경관리
```

이 라이브러리의 핵심은 `P0`를 고정하고 상황에 따라 `P1~P15`만 결합하는 것입니다.  
신규 업무 개발에는 기존 정상 업무 모듈의 실제 파일과 Handler 등록방식을 먼저 확인하도록 강제하는 것이 중요합니다.
