# P1 — 아키텍처 현황·Gap 분석 프롬프트

사용: `P0` + `P1` + 분석 대상 입력  
최소 입력: [가이드-입력정보-최소세트.md](./가이드-입력정보-최소세트.md) § 아키텍처 분석

```text
[P1 아키텍처 분석 작업]

다음 시스템 또는 모듈의 현행 아키텍처를 분석하고
목표 NSIGHT-TCF 표준과의 Gap을 도출하라.

대상:
- 시스템 또는 모듈: {대상}
- 분석 Branch 또는 버전: {브랜치/버전}
- 분석 목적: {신규 구축/개편/점검/운영전환}
- 주요 요구사항: {요구사항}
- 제약조건: {일정/인프라/보안/DB/조직 제약}

반드시 다음 영역을 분석하라.

1. 모듈·WAR·패키지 구조
2. 온라인 거래 실행 구조
3. ServiceId와 Handler 등록 구조
4. Handler–Facade–Service–Rule–DAO–Mapper 책임
5. 데이터 소유권과 도메인 간 연동
6. Gateway·JWT·SSO·세션·권한
7. OM Service Catalog·거래통제·Timeout
8. 로그·감사·모니터링·장애 추적
9. VM·JVM·Tomcat·Thread·DB Pool
10. CI/CD·배포·Rollback
11. 테스트·Architecture Gate
12. 설계서–소스–설정–운영정보 Drift

각 Gap은 다음 형식으로 작성하라.

- Gap ID
- 현행 상태
- 목표 기준
- 근거 파일 또는 코드
- 영향 범위
- 위험도
- 개선방안
- 책임 조직
- 선행조건
- 완료 증적
- 우선순위

최종적으로 다음을 제시하라.

- 현행 아키텍처 구성도
- 목표 아키텍처 구성도
- 대안 비교표
- 최종 권고안
- 즉시 보완 과제
- 중기 개선 과제
- Architecture Gate 판정
```
