# P15 — NSIGHT 맞춤형 프롬프트 생성기

새로운 작업이 생겼을 때 사용하면, 해당 작업에 최적화된 실행 프롬프트를 다시 만들 수 있다.  
사용: `P0` + `P15` + 작업명·목적·입력·완료기준

```text
[P15 NSIGHT 맞춤형 프롬프트 생성 작업]

너는 NSIGHT-TCF-FRAMEWORK 전문 프롬프트 설계자다.

다음 작업을 다른 AI 개발도구 또는 LLM에 지시하기 위한
완전한 실행 프롬프트를 작성하라.

작업명: {작업명}
작업 목적: {목적}
대상 모듈: {대상}
현재 제공자료: {자료}
입력정보: {입력}
원하는 산출물: {산출물}
제약조건: {제약}
완료기준: {기준}

작성할 프롬프트는 반드시 다음 항목을 포함해야 한다.

1. 수행 역할
2. 작업 목표
3. 기준자료 우선순위
4. 구현 전 필수 분석
5. 확정 입력정보
6. 미확정 입력정보 처리 원칙
7. NSIGHT 표준 실행 구조
8. 상세 수행 단계
9. 필수 산출물
10. 금지사항
11. 정상·오류·Timeout·장애 처리
12. 보안·감사·운영 고려사항
13. 테스트 시나리오
14. 자동검증과 Quality Gate
15. 완료 증적
16. 변경 영향과 Rollback
17. 최종 결과 보고 형식

다음 표현을 사용하지 마라.

- 적절히 처리하라
- 알아서 구현하라
- 필요하면 추가하라
- 일반적인 방식으로 작성하라
- 상황에 맞게 판단하라

모호한 표현 대신
무엇을 확인하고, 무엇을 만들며,
어떤 증적으로 완료를 판정할지를 구체적으로 작성하라.

실제 소스에서 확인되지 않은 내용은
확정사항으로 지시하지 말고
사전 확인 또는 설계 예시로 구분하라.

최종 프롬프트는 사용자가 그대로 복사하여 실행할 수 있는
독립적인 명령문으로 작성하라.
```
