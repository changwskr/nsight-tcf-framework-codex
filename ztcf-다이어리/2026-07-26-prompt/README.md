# NSIGHT-TCF-FRAMEWORK 영역별 표준 프롬프트 라이브러리

원본: [`어쩧게 학습할것인가.md`](./어쩧게%20학습할것인가.md)

NSIGHT-TCF 프롬프트는 “코드를 만들어라”보다 **실제 소스 확인 → 차이 분석 → 설계 판단 → 구현 → 증적 검증**을 강제한다.  
요구사항–화면–ServiceId–프로그램–SQL–OM–테스트–운영로그 추적성을 유지하고, 완료는 설계·소스·설정·OM·시험·운영 증적 일치로 판정한다.

## 사용 방식

```text
P0 공통 마스터 프롬프트
        +
P1~P15 영역별 실행 프롬프트
        +
사용자가 제공하는 업무 입력값
```

예시 — 신규 업무 모듈:

```text
P0 + P2 + 업무코드·도메인·테이블·화면정보
```

예시 — CRUD 거래:

```text
P0 + P3 + 화면 이벤트·입출력·테이블 정의
```
