# L11 — 지식을 다시 쓰기 (이해한 것을 재생산)

**선행:** [L10](./L10-테스트-배포-완료증적.md)  
**다음:** 필요 시 작업용 [`../README.md`](../README.md)의 P2~P15로 실전 투입  
**관련 프롬프트:** P2, P12, P13, P14, P15

## 이 단계에서 얻는 것

이해를 **새 모듈 · 문서 · 자동화 · 변경 · 프롬프트 생성**으로 되돌려 쓴다.  
여기부터는 “학습 질의”가 “실전 작업 프롬프트”로 전환된다.

## 왜 맨 마지막인가

만들기(P2)·자동화(P13)·변경(P14)을 너무 일찍 하면  
복붙 구현이 되고 이해는 남지 않는다.  
L00~L10을 통과한 뒤에야 재생산이 학습이 된다.

## 지금 이 질문을 붙여 넣으세요 (트랙 선택)

한 번에 모두 하지 말고 **하나만** 고른다.

### 트랙 A — 신규 모듈로 검증 (권장)

```text
P0 + P2를 적용한다.
단, 즉시 코드를 쓰지 말고 "구현 전 필수 분석 보고서"만 먼저 제출하라.

가상 입력(학습용, 확정 아님):
업무코드: LN / 모듈: ln-service / 기준: eb-service 또는 av-service
ServiceId: LN.Loan.inquiry / 포트: BusinessModuleDefinitions와 충돌 없는 값으로 조사

보고 내용:
1. settings/build/포트/ServiceId 중복 조사 표
2. 복제할 파일 목록과 금지 변형
3. tcf-ui 중계에 넣을 항목
4. 완료 증적 목록 (L10 체크리스트 인용)
5. 내가 아직 모르는 미확정 3가지

분석이 충분하다고 판단되면, 그때 "구현을 진행할까?"라고 나에게 물어라.
임의로 구현을 시작하지 마라.
```
