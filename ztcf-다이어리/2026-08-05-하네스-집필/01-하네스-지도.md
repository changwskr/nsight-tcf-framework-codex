# 01. 하네스 지도

## 1. 하네스가 하는 일

하네스는 AI 코딩을 **무제한 자율 수정**이 아니라 다음으로 제한한다.

1. **범위**: 어디를 고쳐도 되는가
2. **계약**: 어떤 아키텍처·보안·명명을 지켜야 하는가
3. **절차**: 분석 → 승인 → 구현 → 보안 → QA 순서
4. **증적**: 명령·exit code·테스트·보안 리뷰를 남기는가
5. **중단**: 모호하면 추측하지 않고 사용자에게 묻는가

## 2. 레이어 구분

```text
┌─────────────────────────────────────────────────────────┐
│  A. 실행 런타임 (대상 산출물을 고침)                         │
│     tcf-harness-exe-pdmp  →  ../pdmp-service (코드)     │
│     tcf-harness-exe-집필  →  ../ztcfbook (책 Markdown)  │
│     tcf-harness (Java CLI) →  대상 Git 저장소             │
└─────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────┐
│  B. 계약/역할 (문서·핸드오프, 대상 수정 없음 또는 메타)      │
│     tcf-harness-pdmp   — PDMP 아키텍처·역할 계약           │
│     tcf-harness-world  — Analyst/Builder/QA 메타 설계      │
└─────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────┐
│  C. 템플릿/시드                                           │
│     tcf-harness-framework — Claude /harness 빈 껍데기      │
│     tcf-harness-prompt    — Java 하네스용 프롬프트 세트     │
└─────────────────────────────────────────────────────────┘
```

## 3. 관계도

```text
tcf-harness-framework          (Claude 템플릿 시드)
        │ 복사·특화
        ▼
tcf-harness-exe-pdmp ─────────► pdmp-service (구현 대상)
tcf-harness-exe-집필 ─────────► ztcfbook (+ -m/-h)
        │ phases/ + execute.py
        │ AGENTS.md / CLAUDE.md / skills/
        │
        │ 계약 참조
        ▼
tcf-harness-pdmp               (PDMP 계약 SoT 문서)
        │
        │ 메타 패턴 참조
        ▼
tcf-harness-world              (역할·스킬 설계 키트)

tcf-harness + tcf-harness-prompt
        │ Java Gate CLI + prompts
        └─► (별 축) 요건 12문항·수동 승인·상태 JSON
```

## 4. Claude vs Codex 축

| 축 | 패키지 | 진입점 |
|----|--------|--------|
| Claude Code `/harness` | `tcf-harness-framework`, `tcf-harness-exe-pdmp` | `.claude/commands/harness.md`, `skills/harness/` |
| Codex (agents/skills) | `tcf-harness-world`, `tcf-harness-pdmp` | `AGENTS.md`, `agents/*`, `skills/*/SKILL.md` |
| Java CLI Gate | `tcf-harness`, `tcf-harness-prompt` | `bootJar` + `harness/prompts/` |

같은 “하네스”라도 **실행기·계약 언어·승인 방식이 다르다**. 혼용할 때는 어느 축이 SoT인지 먼저 정한다.

## 5. 공통 불변조건 (축 공통)

- 기준 브랜치(`main`/`develop`) 직접 수정 금지 (작업은 기능/하네스 브랜치)
- 자동 Push·Merge 금지 (사용자 명시 요청 전)
- 테스트 삭제·비활성화·조건 완화 금지
- 비밀번호·토큰·개인정보 원문 로그/산출물 금지
- 성공 증적 없으면 완료 보고 금지
- 식별자·스키마·삭제 의미는 **추론하지 말고 질문**

## 6. PDMP 아키텍처 계약 (실행 축 공통)

```text
Controller → Service → DAO → MyBatis
```

- Controller: HTTP 어댑터 + `@TcfTransaction` 선언
- Service: 업무 오케스트레이션·트랜잭션 경계
- DAO: 영속 연산 선언
- MyBatis: SQL + 바인드 파라미터만
- 명명: `MP.{Domain}.{action}` 패턴 (승인된 값만)
- JWT 보호 경로 유지, H2 증적과 Oracle 미검증 분리 기록
