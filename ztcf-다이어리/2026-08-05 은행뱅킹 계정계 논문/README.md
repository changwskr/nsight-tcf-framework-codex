## 한 줄 요약

매일 **00:00 온라인 일자변경** 때 은행 계정계가 수분~수십 분 중단되는 문제를, **디스크 복제 + 원장보정로그(Before Image) + 배치서버 분리**로 풀어 **단 1초도 중단 없이** D-1(전영업일) 마감 원장을 확보하는 설계·시뮬레이션 논문이다.

```text
코어뱅킹 온라인 (무중단)
    │ 동기화 / Split
    ├─► 내부 DR
    │      ├─► 백업 원장 (VTL 백업)
    │      └─► 배치 원장 + 원장보정로그 → D-1 정적원장 → 배치 Job
    └─► Center Cut / FTP 로 운영원장 갱신 (배치 결과)
```
