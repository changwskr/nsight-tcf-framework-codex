## 규칙

1. A16 Gate `통과`/`조건부 통과` 전에 A17 최종 정의서를 확정 발행하지 않는다.  
2. 미실행 검증은 `성공`이 아니라 `미실행`으로 적는다.  
3. 확인 안 된 구조는 `설계 예시` / `미확정`으로 적는다.  
4. 방법론·소스와 충돌하면 차이를 원장에 기록한다.
