한 번에 코드를 만들지 않는다.  
**C-MASTER 고정 → C00→C18 순차 질의 → 단계마다 `결과/`에 저장 → C14 Gate 통과 후에만 C15 코드 생성.**

## 사용 방식

```text
1. C-MASTER를 읽고 대화에 적용한다
2. C00부터 「지금 이 질문을 붙여 넣으세요」를 채팅에 붙인다
3. 답이 오면 확정표를 남기고, 단계 끝나면 결과/Cxx-*.md 저장을 요청한다
4. 「현황」으로 원장을 본다 / 「다음」으로 다음 C로 이동한다
5. C14 Gate 통과 전「코드 생성」을 하지 않는다
```
