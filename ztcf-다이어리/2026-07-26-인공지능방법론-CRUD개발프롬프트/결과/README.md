# CRUD 개발 결과물

단계 프롬프트(`../C00`~`../C18`) 실행 후 **여기**에 확정 마크다운을 저장한다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `_확정정보원장.md` | 전 단계 누적 원장 (매 단계 갱신) |
| `C00-….md` ~ `C18-….md` | 단계별 확정표·산출물 |
| `00-CRUD-완료보고.md` | C18 통합 완료 보고 |

## 단계 확정표 (필수 머리)

| 구분 | 내용 |
| --- | --- |
| 단계 | Cxx |
| 사용자 답변 | … |
| 확정사항 | … |
| 가정·미확정 | `[가정]` / `미확정` |
| 설계 영향 | … |
| 원장 반영 | `_확정정보원장.md` 갱신 항목 |
| 다음 단계 | Cxx+1 |

## 규칙

1. C14 Gate `통과` 또는 `조건부 통과` 전에 C15 코드를 저장소에 쓰지 않는다.
2. 미실행 검증은 `성공`이 아니라 `미실행`으로 적는다.
3. 확인 안 된 클래스·포트·테이블은 `설계 예시` / `미확정`으로 적는다.
4. 방법론 문서와 충돌하면 방법론·소스를 우선하고, 차이를 원장에 기록한다.
