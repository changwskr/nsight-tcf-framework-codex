| 항목 | 내용 |

## 조회 규칙

| 거래 | 규칙 | 위치 |
| --- | --- | --- |
| selectList | `CUSTOMER_NO` 필수 / `CONTACT_TYPE` 선택 | DTO Validation |
| selectList | `USE_YN='Y'`만 | Mapper·DAO |
| selectList | 0건 → 정상 + 빈 목록 | Service 응답 |
| selectDetail | `CONTACT_ID` 필수 | DTO Validation |
| selectDetail | PK면 USE_YN Y/N 모두 | Mapper·DAO |
| selectDetail | 없음 → Not Found 업무 오류 | Rule |
| 공통 | CONTACT_VALUE 마스킹 없음(시범) | — |

## 상태전이

없음. `USE_YN`은 필터·표시용. LN에서 전이하지 않음.
