## 한눈에

```text
서비스요청 → 요건정의 → 영향도분석 → 분석/설계
    → [CM Package 생성]
    → IT개발(개발Server) → 단위/통합테스트
    → 3자테스트 → 인수테스트 (Staging)
    → 이관/배포 → 운영 (운영Server)
    → [CM Package 종료]
```

| 구분 | 주 관할 | 구간 |
|------|---------|------|
| **형상관리** | 소스 Check-in/out·점검 | 개발Server (IT 개발) |
| **변경관리** | 환경 승격·테스트·이관 | 단위/통합 → Staging → 운영 이관 |
| **기반** | iQMS 전 구간, PMS 산출물 등록 | 요청~운영 |
