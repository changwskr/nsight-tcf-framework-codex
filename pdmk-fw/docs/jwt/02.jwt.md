주석 1 현재 실행 환경에는 `PDMK_JWT_SECRET` 환경변수가 설정되어 있지 않습니다.

따라서 Spring이 실제로 사용하는 값은 콜론 뒤의 기본값입니다.

```text
pdmk-local-dev-secret-key-change-me-32b
```

설정 문법 전체는 다음과 같습니다.

```yaml
secret: "${PDMK_JWT_SECRET:pdmk-local-dev-secret-key-change-me-32b}"
```

Spring의 결정 방식:

```text
PDMK_JWT_SECRET 환경변수 존재?
  ├─ 예 → 환경변수의 실제 값 사용
  └─ 아니오 → pdmk-local-dev-secret-key-change-me-32b 사용
```

현재 상태는 다음과 같습니다.

```text
활성 프로파일: local
PDMK_JWT_SECRET: 설정 안 됨
최종 jwt.secret: pdmk-local-dev-secret-key-change-me-32b
```

이 문자열은 토큰 자체가 아니라 JWT의 HMAC 서명을 만들고 검증하는 공유 비밀키입니다.

```text
tcf-jwt 또는 인증 서버
  └─ 같은 Secret으로 JWT 서명

pdmk-service
  └─ 같은 Secret으로 JWT 서명 검증
```

발급 서버가 다른 Secret을 사용하면 PDMK의 `JwtProvider.validate()`가 `false`를 반환합니다.

운영에서는 기본값을 사용하면 안 되고, 서버 실행 전에 다음처럼 별도의 안전한 값을 넣어야 합니다.

```powershell
$env:PDMK_JWT_SECRET = "운영용으로-안전하게-관리되는-충분히-긴-비밀키"
.\gradlew.bat bootRun
```

다만 이렇게 설정한 환경변수는 현재 PowerShell 프로세스와 그 자식 프로세스에만 적용됩니다. 운영 배포에서는 컨테이너 Secret, Kubernetes Secret 또는 배포 서버의 환경변수로 주입해야 합니다.
