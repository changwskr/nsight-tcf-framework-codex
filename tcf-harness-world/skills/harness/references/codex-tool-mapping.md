# Codex 협업 도구 매핑

| 목적 | 도구 | 계약 |
|---|---|---|
| 독립 작업 시작 | `spawn_agent` | 경계가 명확하고 에이전트 사용이 허용된 작업만 배정한다. |
| 실행 중 정보 전달 | `send_message` | 범위를 바꾸지 않는 사실과 제약을 전달한다. |
| 완료 후 추가 작업 | `followup_task` | 기존 역할 문맥을 유지한 제한된 후속 작업을 시작한다. |
| 결과 대기 | `wait_agent` | 시간 제한을 두고 상태 변경을 기다린다. |

도구 호출 자체가 권한을 확대하지 않는다. 삭제, 외부 게시, 브랜치 통합과 같은 상태 변경은 사용자 요청과 저장소 지침의 범위 안에서만 수행한다.
