# PDMK 통합 아키텍처 정의서 가독성 개선 Word 제작 설계

## 목적

`pdmk-service/docs/통합 아키텍처 정의서 copy.md`의 내용을 개발자와 아키텍트가 처음부터 순서대로 이해하고 필요할 때 빠르게 참조할 수 있도록 재구성한 Word 문서를 생성한다.

## 편집 방향

- 전체 그림 → 실행 흐름 → 업무 구현 → 공통 품질 → 플랫폼·운영 → AS-IS 현황·부록 순으로 재배치한다.
- 반복되는 목차, 표 그림, 같은 의미의 요약표와 설명은 하나로 통합한다.
- AS-IS 사실, 현재 활성 경로, 조건부·비활성 경로를 구분한다.
- 코드 예시는 계약과 실행 흐름을 이해하는 데 필요한 최소 범위로 축약한다.
- 각 장에 학습 목표와 핵심 체크리스트를 둔다.
- API, 클래스, 설정, 테이블, SQL ID 등 상세 정보는 부록 색인으로 보존한다.

## 디자인

- Word 프리셋: `compact_reference_guide`
- 첫 페이지: `editorial_cover`
- Letter 세로, 1인치 여백, 맑은 고딕 중심 한글 타이포그래피
- 청색 제목 계층, 청회색 표 머리글, 밝은 상태 Callout
- 시스템 컨텍스트, 모듈 의존, 거래 시퀀스, 데이터·TX 흐름 다이어그램 포함
- 고정폭 표, 반복 머리글, 실제 Word 제목·목록·페이지 필드 사용

## 검증

- 원본의 핵심 29절 주제가 새 17개 장 또는 부록에 매핑되어야 한다.
- 현재 활성 legacy-web과 조건부 TCF 경로가 명확히 구분되어야 한다.
- 중복된 목차·표 그림이 본문에 반복되지 않아야 한다.
- DOCX 접근성 감사를 수행한다.
- PDF/PNG로 전 페이지 렌더링하고 표·그림·코드·머리글·바닥글을 시각 검토한다.
