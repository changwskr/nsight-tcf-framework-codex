`jwt.enabled=true`일 때 `ServicePreventionInterceptor`가 점검하는 항목은 다음과 같습니다.

1. **헤더 존재** — `Authorization: Bearer {token}` 있는지
2. **서명** — RS256이면 pdmg-jwt JWKS 공개키, HS256이면 `jwt.secret`
3. **만료** — `exp`가 지나지 않았는지
4. **Access 여부** — claim `type == ACCESS` (없더라도 RS256이면 Access로 인정)
5. **사용자 식별** — 통과 시 `userId`/`sub` → `ssoId`(로그의 `admin01`)

점검하지 않는 것: issuer/audience 강제, refresh 토큰, deny-list, 권한(role) 등.

`jwt.enabled=false`이면 위 점검을 **전부 생략**합니다.
