### Access Token 발급 흐름

```text
사용자 / SSO
    │
    │ 로그인 요청
    ▼
JWT Controller
    │
    ▼
mgjwa1000Handler
    │
    ▼
mgjwa1000Facade
    │
    │ 트랜잭션 시작
    ▼
mgjwa1000Service
    │
    ├─ 사용자 조회
    ├─ 비밀번호·계정 상태 검증
    ├─ Access Token JTI 생성
    └─ JwtTokenIssuer 호출
            │
            ├─ JWT Header 작성
            │     alg = RS256
            │     kid = nsight-jwt-rs256
            │     typ = JWT
            │
            ├─ JWT Claim 작성
            │     iss       = NSIGHT-AUTH
            │     aud       = NSIGHT-MP
            │     sub       = 사용자 ID
            │     jti       = 토큰 고유 ID
            │     type      = ACCESS
            │     userId    = 사용자 ID
            │     branchId  = 영업점 ID
            │     channelId = 채널 ID
            │     exp       = 만료 시각
            │
            └─ RSA Private Key로 전자서명
                    │
                    ▼
              RS256 Access Token
                    │
                    ▼
             Token 이력 DB 저장
                    │
                    ▼
             트랜잭션 COMMIT
                    │
                    ▼
              사용자에게 반환
```

### RSA Key 구조

```text
현재 구현

pdmg-jwt 시작
    │
    ▼
JwtKeyConfiguration
    │
    ▼
RSA 2048 Key Pair 생성
    │
    ├─────────────────────────────┐
    │                             │
    ▼                             ▼
Private Key                    Public Key
    │                             │
    │ JVM 메모리 보관             │ JWKSet 변환
    │                             │
    ▼                             ▼
JwtTokenIssuer                JwkSetController
    │                             │
    │ RS256 서명                  │ JWKS API 공개
    ▼                             ▼
Access Token             /.well-known/jwks.json
```

현재는 서버가 재기동될 때 RSA Key Pair가 다시 생성됩니다.

```text
서버 재기동
    │
    ▼
새로운 RSA Key Pair 생성
    │
    ▼
기존 Public Key 폐기
    │
    ▼
기존 발급 토큰 검증 불가능
```

운영 권장 구조는 다음과 같습니다.

```text
Vault / KMS / KeyStore / Secret
              │
              │ 동일한 Private Key 제공
              ▼
          pdmg-jwt
              │
              ├─ Private Key로 JWT 서명
              │
              └─ Public Key를 JWKS로 공개
```

### 토큰 재발급 흐름

```text
Refresh Token 요청
    │
    ▼
JWT Controller
    │
    ▼
Handler → Facade
    │
    ▼
JWT Service
    │
    ├─ Refresh Token Hash 조회
    ├─ 토큰 만료 여부 확인
    ├─ 토큰 폐기 여부 확인
    ├─ 사용자 상태 확인
    ├─ 기존 Refresh Token 폐기
    ├─ 신규 Access Token 생성
    └─ 신규 Refresh Token 생성
            │
            ▼
     Refresh Token Rotation
            │
            ▼
        DB 저장 및 COMMIT
            │
            ▼
   신규 Access/Refresh Token 반환
```

### 로그아웃 흐름

```text
로그아웃 요청
    │
    ▼
Access Token 식별
    │
    ├─ Access Token JTI를 Denylist에 등록
    ├─ 연관 Refresh Token 폐기
    └─ 로그아웃 이력 저장
            │
            ▼
     이후 토큰 재사용 차단
```

### pdmg-jwt의 핵심 책임

```text
pdmg-jwt
  ├─ 사용자 인증
  ├─ SSO 인증 결과 연계
  ├─ Access Token 생성
  ├─ Refresh Token 생성
  ├─ RS256 전자서명
  ├─ Public Key JWKS 공개
  ├─ Refresh Token Rotation
  ├─ 로그아웃
  ├─ 토큰 강제 폐기
  ├─ Denylist 관리
  └─ 토큰 발급·사용 이력 관리
```
