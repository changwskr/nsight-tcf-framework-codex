`32.범용CRUD프롬프트`는 **AI에게 CRUD 구현을 시킬 때 쓰는 템플릿**입니다. 사용 순서는 문서 §1과 같습니다.

### 사용 순서

1. **§4 요구사항 입력 양식**을 채운다
   - 프로그램 ID, 테이블/PK, 서비스 ID(S0/C0/U0/D0), 검색·페이징, 업무 규칙 등
   - 모르는 항목은 추측하지 말고 `[미정 — 질문 필요]`

2. **§7 범용 CRUD 최종 프롬프트**에서 `[대괄호]`를 실제 값으로 바꾼다
   - 일부만 필요하면 **§8 기능별 축약 프롬프트** 사용

3. Cursor 채팅에 **최종 프롬프트를 붙여 넣고** 요청한다
   - 권장: “먼저 조사·설계·영향 파일만 보고 → 승인 후 구현”

4. 구현 후 **§9 체크리스트**로 검수한다

### 한 줄로

```text
§4 양식 작성 → §7(또는 §8) 프롬프트에 값 채우기 → AI에 붙여넣기 → §9 검수
```

참조 구현은 `mgcoa9000`/`mgcoa8888` 패턴을 따르고, 테이블·서비스 ID·오류 코드는 **복사하지 말고** 양식에 적은 계약만 쓰게 하면 됩니다.
