```text
[현재 구현]

pdmg-jwt
  │
  │ RSA Private Key
  │ RS256 서명
  ▼
RS256 Access Token
  │
  ▼
pdmg-service
  │
  ▼
pdmg-fw DefaultFilter
  │
  ▼
JwtProvider
  │
  │ jwt.secret 기반 HMAC 검증
  ▼
검증 실패 가능
```

정상적으로 연결하려면 다음 구조가 되어야 합니다.

```text
[권장 구조]

pdmg-jwt
  │
  ├─ Private Key ──▶ RS256 JWT 서명
  │
  └─ Public Key ───▶ /.well-known/jwks.json
                              │
                              ▼
pdmg-fw DefaultFilter
  │
  ▼
RS256 JwtDecoder
  │
  ├─ JWKS Public Key 조회·캐시
  ├─ kid에 맞는 키 선택
  ├─ 전자서명 검증
  ├─ exp / nbf 만료 검증
  ├─ issuer 검증
  ├─ audience 검증
  └─ type=ACCESS 검증
  │
  ▼
ServiceContext에 ssoId·권한 정보 저장
  │
  ▼
pdmg-service 업무 처리
```
