## 5. TransactionContext 구조

```text
TransactionContext
│
├─ serviceId
│   └─ 현재 실행할 거래 ID
│
├─ serviceContext
│   ├─ GUID
│   ├─ 표준 Header
│   ├─ Request / Response
│   ├─ 사용자 ID
│   ├─ 영업점
│   └─ 채널 정보
│
└─ startedAtNanos
    └─ 전체 거래 경과시간 계산
```

생성 흐름:

```text
DefaultFilter
   │
   └─ ServiceContextHolder 설정
           │
           ▼
OnlineTransactionController
           │
           ▼
TransactionContext.fromCurrent(serviceId)
           │
           ├─ Service ID 저장
           ├─ 현재 ServiceContext 연결
           └─ 시작 시각 저장
```

## 7. 트랜잭션 경계

```text
TcfFacade
  │
  ├─ STF
  │
  ├─ TransactionDispatcher
  │      │
  │      ▼
  │   Handler
  │      │
  │      ▼
  │   Business Facade
  │      │
  │      ├══════════════════════════════════╗
  │      ║ DB 트랜잭션                     ║
  │      ║                                  ║
  │      ║ BEGIN                            ║
  │      ║   → BizPre                       ║
  │      ║   → Service                      ║
  │      ║   → Rule                         ║
  │      ║   → DAO / Mapper                 ║
  │      ║   → BizPost                      ║
  │      ║ COMMIT 또는 ROLLBACK             ║
  │      ╚══════════════════════════════════╝
  │
  └─ ETF
```

기본적으로 TCF 전체가 하나의 DB 트랜잭션인 것은 아닙니다.

```text
트랜잭션 밖
├─ DefaultFilter
├─ Interceptor
├─ OnlineTransactionController
├─ TcfFacade
├─ STF
└─ TransactionDispatcher 일부

트랜잭션 안
├─ Business Facade
├─ BizPre
├─ Service
├─ Rule
├─ DAO / Mapper
└─ BizPost

다시 트랜잭션 밖
└─ ETF
```

## 9. 타임아웃 처리

```text
TransactionContext 생성
      │
      └─ startedAtNanos 기록
      │
      ▼
STF → Handler → 업무 처리
      │
      ▼
ETF
      │
      ├─ elapsedMs 계산
      ├─ timeoutMs 조회
      └─ 경과시간 비교
      │
      ├─ elapsedMs ≤ timeoutMs
      │      └─ 정상 종료
      │
      └─ elapsedMs > timeoutMs
             └─ OnlineTimeoutException
```

현재 소스에는 다음 메서드 불일치가 있습니다.

```text
ETF 호출                         실제 구현
──────────────────────────────────────────────────
resolveMilliseconds(serviceId)  존재하지 않음
elapsedMsSinceStart()            elapsedMs()
```

이 불일치를 해결하기 전에는 현재 `pdmg-fw` 컴파일이 실패합니다.

## 10. 설정에 따른 활성화

```text
application.yml

nhnis:
  fw:
    tcf:
      enabled: true
```

활성화:

```text
TCF enabled=true

/online
  → OnlineTransactionController
  → TcfFacade
  → STF
  → Dispatcher
  → Handler
  → ETF
```

비활성화:

```text
TCF enabled=false

/업무ServiceId
  → 업무 Controller
  → Facade
  → Service
  → DAO
```

TCF가 꺼지면 다음 기능이 자동으로 실행되지 않을 수 있습니다.

```text
TCF 비활성화 영향
├─ OnlineTransactionController 미생성
├─ TransactionDispatcher 미생성
├─ TcfFacade 미생성
├─ STF 미실행
├─ ETF 미실행
└─ Handler 기반 Service ID 라우팅 미사용
```

## 11. TCF 핵심 책임

```text
TCF
├─ 표준 온라인 거래 진입점 제공
├─ 표준 전문 Header와 Body 처리
├─ Service ID 기반 거래 라우팅
├─ TransactionHandler 자동 등록
├─ TransactionContext 생성
├─ ServiceContext 연계
├─ 시스템 선처리(STF)
├─ 업무 실행 조정
├─ 시스템 후처리(ETF)
├─ 타임아웃 확인
├─ 거래 흐름 로그
├─ 예외 전달
└─ 표준 응답 생성
```
