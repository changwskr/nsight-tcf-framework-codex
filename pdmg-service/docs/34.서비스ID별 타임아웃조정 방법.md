**serviceId별 `overrides`에 ms를 넣으면 됩니다.**

### `pdmg-service` `application.yml`

```yaml
nhnis:
  fw:
    timeout:
      enabled: true
      milliseconds: 5000 # 기본
      overrides:
        mgcoa5530S0: 10000 # 이 거래만 10초
        mgcoa7000S0: 15000 # 예: 15초
```

- 키 = 서비스 ID (`rms_svc_c`와 동일)
- 값 = 제한시간(ms)
- 미등록 = `milliseconds` 사용

### 기동 옵션으로만 올릴 때

```text
--nhnis.fw.timeout.overrides.mgcoa5530S0=10000
```

반영 후 **pdmg-service 재기동**.  
UI `pdmg.ui.timeout-ms`(브라우저 Abort)는 별개이므로, 서버보다 **크거나 같게** 두는 것이 좋습니다.
