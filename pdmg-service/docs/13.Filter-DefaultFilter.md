## 1. 역할

`DefaultFilter`는 HTTP 요청이 **DispatcherServlet / Handler에 들어가기 전**에 도는 **Servlet Filter**다.

| 한다 | 하지 않는다 |
|------|-------------|
| Body 캐시 (재읽기 가능) | 업무 Service/DAO 호출 |
| JWT 검증 (비-local) | `@Transactional` / DB 업무 TX |
| `hdr_nhnis` 파싱·local 합성 | ImageLog INSERT (Interceptor) |
| `ServiceContext` / MDC 준비 | `NH_NIS_ERR_DTO` 조립 |
| `PDMG_REQUEST_BODY` attribute | 서비스 ID 라우팅 (Handler) |

```text
HTTP POST /{serviceId}
  → DefaultFilter                    ★ 본 문서
  → SecurityFilterChain (permitAll)
  → DispatcherServlet
  → ServicePreventionInterceptor
  → OnlineTransactionController → Handler → Facade…
```

기반: `OncePerRequestFilter` — FORWARD/ERROR 디스패치에서 중복 실행 방지.

---

## 2. 활성·등록

### 2.1 설정 (`application.yml`)

```yaml
nhnis:
  fw:
    commons:
      filter:
        enabled: true
```

| 조건 | 효과 |
|------|------|
| `nhnis.fw.commons.filter.enabled=true` | Bean + `FilterRegistrationBean` |
| `spring.profiles.active=local` | JWT 생략, hdr 없으면 합성 |

### 2.2 `FilterConfiguration`

```text
Filter: DefaultFilter
Name:   pdmgDefaultFilter
URL:    /*
DispatcherType: REQUEST
Order:  Ordered.HIGHEST_PRECEDENCE + 20
```

`@Component` 자동 서블릿 등록과 겹치지 않도록 **RegistrationBean만** 매핑한다.

| 항목 | 값 |

## 4. 처리 순서 (`doFilterInternal`)

```text
enter TX-FLOW
│
├─ URI 마지막 세그먼트 → serviceId 후보 → ThreadContext(serviceId)
│
├─ Content-Type multipart?
│     YES → X-GUID 등 최소 hdr/Context → chain.doFilter → finally 정리
│     NO  ↓
│
├─ CachedBodyHttpServletRequest wrapper
│
├─ profile ≠ local?
│     Authorization Bearer 필수
│     JwtProvider.validate / isAccessToken
│     실패 → 401 sendError (종료)
│     성공 → request attribute ssoId
│
├─ Body 읽기 (wrapper)
│     비어 있음 → 400
│
├─ JSON → Map
│     파싱 실패 → 400
│
├─ root.hdr_nhnis
│     null + 비-local → 400 "공통 Header 정보가 없습니다"
│     null + local    → syntheticLocalHeader (UUID GUID, rms_svc_c←path …)
│     있음            → convert → hdr_nhnis + enrichMissingSysComm
│
├─ ThreadContext: guid, ip, userId, serviceId(rms_svc_c 우선)
├─ ServiceContext 생성 → ServiceContextHolder
├─ wrapper.setAttribute(PDMG_REQUEST_BODY, raw)
├─ ctx.setRequestBody(raw)
│
├─ filterChain.doFilter(wrapper, response)
│
└─ finally
      ServiceContextHolder.removeInstance()
      ThreadContext.clearAll()
      leave TX-FLOW
```

일반 예외 catch → ERROR 로그 + **400** `sendError("Filter 처리 중 Exception 발생")`.

## 5. 세부 동작

### 5.1 Body 캐시

Servlet InputStream은 한 번만 읽을 수 있다. Filter에서 JSON을 파싱하므로 `CachedBodyHttpServletRequest`로 감싸 이후 Controller/Resolver가 다시 읽는다.

Interceptor는 `PDMG_REQUEST_BODY` 또는 Context/캐시에서 요청 전문 원문을 가져온다.

주의: Body 전체를 메모리에 올린다. 거대 페이로드·파일은 multipart 경로를 검토.

### 5.2 JWT (프로파일)

`jwt.enabled`가 아니라 **`spring.profiles.active`** 로 분기.

| 프로파일 | 동작 |
|----------|------|
| `local` | Authorization 없어도 통과 |
| 그 외 | `Bearer` Access Token 필수 · validate · access 타입 · `ssoId` |

앱 `SecurityConfig`는 `permitAll` → **비-local 인증 강제점은 DefaultFilter**.

### 5.3 헤더 합성·보강 (local / 부분 헤더)

`syntheticLocalHeader` / `fillSysCommFromRequest`:

| 필드 | 비어 있을 때 |
|------|----------------|
| `std_gbl_id` | UUID (하이픈 제거) |
| `rms_svc_c` | path serviceId |
| `scid` | 서비스 ID에서 `[SD]\d+$` 제거 |
| `tr_trm_ipadr` | X-Forwarded-For 또는 remoteAddr |
| `optr_eno` | `"LOCAL"` |
| `tr_sysid` | `spring.application.name` |

### 5.4 산출물

| 산출 | 소비자 |
|------|--------|
| `ServiceContext` | Interceptor, Advice, ImageLog |
| ThreadContext | 로그 MDC (guid, serviceId, userId, ip) |
| `PDMG_REQUEST_BODY` | Interceptor 요청전문 로그 |
| Cached wrapper | Controller `@RequestBody` 재읽기 |

## 6. 실패 응답 특성

| 실패 | HTTP | 비고 |
|------|------|------|
| 토큰 없음/무효 | 401 | `sendError` — `GlobalExceptionHandler` 미경유 |
| Body 없음·JSON·hdr 없음(비-local)·Filter 예외 | 400 | 동상 |
| 업무 `BizException` | Advice 경로 | Filter 밖 → [11.예외처리.md](./11.예외처리.md) |

Filter 단계 오류는 성공 전문 봉투(`hdr_nhnis`+`dto`)와 스키마가 다를 수 있다.

---

## 7. Security와의 관계

`nhnis.mg.co.a.config.SecurityConfig`:

- CSRF off, STATELESS, form/httpBasic off  
- `anyRequest().permitAll()`  
- **TCF `JwtAuthenticationFilter` 미사용** — JWT는 DefaultFilter

FW commons `SecurityConfig`는 `nhnis.fw.commons.security.enabled=true`일 때만 (기본 off).

## 11. 요약

```text
DefaultFilter = 요청 준비 Filter
  Body 캐시 + (비-local) JWT + hdr_nhnis/ServiceContext + MDC
  → chain → Interceptor(시스템 선처리) → TCF/Handler → Facade(TX)

ImageLog·업무 예외·응답 봉투는 DefaultFilter 밖이다.
```
