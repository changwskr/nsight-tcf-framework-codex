# 19. Business Facade (PDMG)

기준일: 2026-08-09  
대상: `nhnis.mg.co.a.application.facade.*`  
관련: [18.Business-Handler.md](./18.Business-Handler.md) · [20.Tranaactional-rdwTransactionManager-Begin.md](./20.Tranaactional-rdwTransactionManager-Begin.md) · [22.Business-Service.md](./22.Business-Service.md) · [트랜잭션처리.md](./트랜잭션처리.md) · [17.TCF-TcfFace-Dispatcher.md](./17.TCF-TcfFace-Dispatcher.md)

---

## 1. 역할

Handler와 Service 사이에서 **DB 트랜잭션 경계**와 **`dto` → `*DTOin` 변환**을 맡는 업무 진입 Facade다.

```text
*Handler.handle
  → *Facade.mgcoaXXXXYn(Object dtoBody)   ★ @Transactional
       1) objectMapper.convertValue → *DTOin
       2) service.mgcoaXXXXYn(input)
  → *DTOout 반환
```

| 한다 | 하지 않는다 |
|------|-------------|
| `@Transactional(rdwTransactionManager)` | SQL / DAO 직호출 |
| Map/`Object` → `*DTOin` | 업무 절차·규칙 (Service) |
| 같은 서비스 ID의 Service 메서드 1회 호출 | serviceId 라우팅 (Handler) |
| 조회 `readOnly` / 쓰기 `rollbackFor` 구분 | 응답 `{ hdr_nhnis, dto }` 조립 |

한 줄: **TX + 바인딩. 일은 Service.**

---

## 2. TcfFacade와 구분

| | **TcfFacade** (FW) | **mgcoa\*Facade** (업무) |
|--|--------------------|--------------------------|
| 패키지 | `nhnis.fw.tcf.core.facade` | `nhnis.mg.co.a.application.facade` |
| 역할 | Dispatcher 호출 | DB TX + DTO 변환 + Service |
| `@Transactional` | 없음 | **있음** |
| 메서드 | `process(serviceId, dto)` | `mgcoa8888S0(dtoBody)` 등 |

이름만 Facade로 같다. 트랜잭션·업무 경계는 **업무 Facade**다.

---

## 3. 위치 · 네이밍

| 항목 | 규칙 |
|------|------|
| 패키지 | `nhnis.mg.co.a.application.facade` |
| 클래스 | `{프로그램접두}Facade` — 예: `mgcoa8888Facade` |
| 스테레오타입 | `@Service` (스프링 빈; 레이어명은 Facade) |
| 메서드명 | **서비스 ID와 동일** — `mgcoa8888S0`, `mgcoa9000C0` |
| 인자 | `Object dtoBody` (전문 `dto` 노드) |
| 반환 | 대응 `*DTOout` |

샘플: `mgcoa5530` / `8888` / `9000` / `9999` Facade.

---

## 4. 표준 본문

```java
@Service
public class mgcoa8888Facade {

    private final mgcoa8888Service service;
    private final ObjectMapper objectMapper;

    @Transactional(transactionManager = "rdwTransactionManager", readOnly = true)
    public mgcoa8888S0DTOout mgcoa8888S0(Object dtoBody) throws Exception {
        mgcoa8888S0DTOin input = convert(dtoBody, mgcoa8888S0DTOin.class);
        return service.mgcoa8888S0(input);
    }

    @Transactional(transactionManager = "rdwTransactionManager", rollbackFor = Exception.class)
    public mgcoa8888D0DTOout mgcoa8888D0(Object dtoBody) throws Exception {
        mgcoa8888D0DTOin input = convert(dtoBody, mgcoa8888D0DTOin.class);
        return service.mgcoa8888D0(input);
    }

    private <T> T convert(Object dtoBody, Class<T> type) {
        Object source = dtoBody == null ? Collections.emptyMap() : dtoBody;
        return objectMapper.convertValue(source, type);
    }
}
```

| 구분자 | TX 옵션 (관례) |
|--------|----------------|
| `S` (조회) | `readOnly = true` |
| `C`/`U`/`D` (쓰기) | `rollbackFor = Exception.class` |

TM 빈: `rdwTransactionManager` (`RdwDataSourceConfig`). 상세 BEGIN/COMMIT: [20](./20.Tranaactional-rdwTransactionManager-Begin.md).

## 5. 호출 순서와 Aspect

```text
Handler → Facade 프록시
  → BEGIN (rdwTransactionManager)
  → convert(dtoBody → DTOin)     ← 아직 Service 전, TX 안
  → service.xxx(input)
       → BizPrePostAspect 선처리   ← pointcut: application.service
       → Service / DAO / SQL
       → BizPrePostAspect 후처리
  → return DTOout
  → COMMIT (예외 시 ROLLBACK)
```

| 관심사 | 위치 |
|--------|------|
| DB TX | **Facade** 메서드 |
| 업무 선·후처리 | **Service** (`BizPrePostAspect`) — Facade TX **안** |
| 시스템 선·후 / ImageLog | Filter · Interceptor · Advice — Facade TX **밖** |

변환 실패(`IllegalArgumentException` 등)도 Facade 메서드 안에서 나면 쓰기 TX는 rollback 대상이 될 수 있다.

---

## 6. Handler / Service와의 계약

| From → To | 넘기는 것 |
|-----------|-----------|
| Handler → Facade | `Object dtoBody` (미변환) |
| Facade → Service | `*DTOin` (타입 확정) |
| Service → Facade | `*DTOout` |
| Facade → Handler | 동일 `*DTOout` (`Object`로 상향) |

- Facade는 **DAO를 주입하지 않는다**.
- Service는 Facade 없이 Handler/Controller에서 직접 호출되면 TX가 빠질 수 있다 (TCF OFF 샘플 Controller 주의).

---

## 7. 신규 거래

같은 프로그램에 거래 추가:

1. Facade에 `mgcoaXXXXYn(Object dtoBody)` + `@Transactional`  
2. `convert` → 대응 Service 메서드  
3. Handler `switch`에 연결 ([18](./18.Business-Handler.md))

새 프로그램: `mgcoaNNNNFacade` 신규 + Service/DAO/DTO.

---

## 8. 하지 말 것

1. Facade에서 SQL·Mapper·DAO 호출  
2. TX를 Service/Handler/TcfFacade로 옮기기  
3. 메서드명을 서비스 ID와 다르게 짓기  
4. 전문 전체(`hdr_nhnis` 포함)를 `convert`에 넣기 — **`dto`만**  
5. 조회에 불필요하게 쓰기 TX / 쓰기에 `readOnly=true`  
6. Facade 본문에 긴 업무 if·루프 (Service로)
