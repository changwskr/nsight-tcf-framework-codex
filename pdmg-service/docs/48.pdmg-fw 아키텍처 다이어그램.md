## 핵심 거래 호출 흐름

```text
HTTP 요청
   │
   ▼
DefaultFilter
   ├─ JWT 검증
   ├─ GUID 생성
   └─ ServiceContext 생성
   │
   ▼
ServicePreventionInterceptor
   ├─ 시스템 선처리
   └─ 거래 통제
   │
   ▼
OnlineTransactionController
   │
   ▼
TcfFacade
   │
   ├─ STF
   │    └─ 시스템 선처리
   │
   ├─ TransactionDispatcher
   │    └─ Service ID에 대응하는 Handler 검색
   │
   ├─ pdmg-service TransactionHandler
   │    └─ 업무 Facade 및 Service 실행
   │
   └─ ETF
        ├─ 시스템 후처리
        └─ 타임아웃 확인
   │
   ▼
표준 응답 또는 GlobalExceptionHandler
   │
   ▼
ServiceContext / MDC 정리
```

## TCF 구성요소 관계

```text
                    TcfFacade
                        │
           ┌────────────┼────────────┐
           │            │            │
           ▼            ▼            ▼
          STF     TransactionDispatcher     ETF
           │            │                   │
           │            ▼                   │
           │      TransactionHandler        │
           │            │                   │
           │            ▼                   │
           │       업무 애플리케이션         │
           │            │                   │
           └────────────┴───────────────────┘

STF
 └─ 거래 실행 전 시스템 공통 처리

TransactionDispatcher
 └─ Service ID를 기준으로 업무 Handler 호출

ETF
 └─ 거래 실행 후 시스템 공통 처리 및 타임아웃 확인
```

## 트랜잭션 구조

```text
pdmg-fw
  TcfFacade
      │
      │ 업무 Handler 호출
      ▼
pdmg-service
  TransactionHandler
      │
      ▼
  업무 선처리
      │
      ▼
  Business Facade
      │
      │ @Transactional(
      │     transactionManager = "rdwTransactionManager",
      │     rollbackFor = Exception.class
      │ )
      │
      ├────────── 트랜잭션 시작
      │
      ▼
  Business Service
      │
      ▼
  Rule
      │
      ▼
  DAO / Mapper
      │
      ▼
  업무 DB
      │
      ├─ 정상 반환 ───────▶ COMMIT
      └─ 예외 발생 ───────▶ ROLLBACK
```

`pdmg-fw`의 STF·ETF·Dispatcher 자체가 DB 트랜잭션을 시작하는 것은 아닙니다. 현재 기본 트랜잭션 경계는 업무 모듈의 `Business Facade`입니다.

## 타임아웃 구조

```text
application.yml
  nhnis.fw.timeout
      │
      ├─ enabled
      ├─ milliseconds
      ├─ pool-size
      └─ queue-capacity
      │
      ▼
OnlineTimeoutProperties
      │
      ▼
OnlineTimeoutConfiguration
      │
      ├─ enabled=false
      │      └─ 직접 실행
      │
      └─ enabled=true
             └─ DefaultOnlineTimeoutExecutor
                       │
                       ├─ 별도 작업 실행
                       ├─ 제한 시간 감시
                       ├─ 제한 초과 시 작업 취소
                       └─ OnlineTimeoutException 발생
```

현재 소스에는 타임아웃 변경 과정에서 메서드 불일치가 있습니다.

```text
etf 호출                          실제 구현
────────────────────────────────────────────────────
resolveMilliseconds(serviceId)   메서드 없음
elapsedMsSinceStart()             elapsedMs()
```

따라서 이 부분을 맞추기 전에는 `pdmg-fw` 및 이를 참조하는 `pdmg-jwt` 빌드가 실패합니다.

## pdmg-fw의 책임 요약

```text
pdmg-fw
 ├─ HTTP Filter
 ├─ JWT 검증
 ├─ 표준 전문 처리
 ├─ ServiceContext 관리
 ├─ GUID·MDC 관리
 ├─ Spring MVC 확장
 ├─ 시스템 선처리(STF)
 ├─ 거래 Handler 탐색과 실행
 ├─ 시스템 후처리(ETF)
 ├─ 타임아웃 관리
 ├─ DataSource·TransactionManager 구성
 ├─ 표준 예외 처리
 ├─ 공통 메시지 처리
 ├─ 거래 흐름 로깅
 └─ 요청 종료 자원 정리
```
