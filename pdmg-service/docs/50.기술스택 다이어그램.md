## 보안 기술 구조

```text
HTTPS
  │
  ▼
Bearer Access Token
  │
  ▼
DefaultFilter
  │
  ▼
JWT 서명 검증
  │
  ├─ 현재    : HMAC + jwt.secret
  └─ 권장    : RS256 + JWKS Public Key
  │
  ▼
Claim 검증
  │
  ├─ iss  : 발급자
  ├─ aud  : 대상 시스템
  ├─ exp  : 만료 시간
  ├─ nbf  : 사용 가능 시작 시간
  ├─ jti  : 토큰 고유번호
  └─ type : ACCESS
  │
  ▼
ServiceContext
  │
  ├─ ssoId
  ├─ branchId
  ├─ channelId
  └─ authGroupId
  │
  ▼
업무 거래 실행
```

현재 저장소 기준상 Java 버전은 `21`입니다. 다만 저장소 공통 기준은 Spring Boot `3.3.5`이고 신규 `pdmg-jwt`는 `3.5.14`를 사용하므로, 통합 배포 전 버전 정합성 검증이 필요합니다.
