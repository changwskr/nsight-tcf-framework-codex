**맞습니다.** `nhnis.fw.timeout.enabled=true` 일 때 그렇게 나뉩니다.

### 역할

| 스레드                        | 하는 일                                                                                                    |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **요청 스레드** (Tomcat/HTTP) | Filter·시스템 선처리 → Controller → `TcfFacade` → `Future.get(timeout)` 대기 → 응답·시스템 후처리·ImageLog |
| **Worker 스레드** (풀)        | **TX BEGIN** → Handler → 업무 Facade → Service → DAO → 업무 선/후처리 → **COMMIT/ROLLBACK**                |

```text
요청 스레드:  TcfFacade → submit(Worker) → Future.get(제한시간)
Worker:       TransactionTemplate { Handler → Facade → Service → DAO }
```

### 참고

- `timeout.enabled=false` 이면 `SyncOnlineTimeoutExecutor`라 **분리 없이** 요청 스레드에서 동기 실행합니다.
- 타임아웃 시 요청 스레드는 바로 `FW_TIMEOUT`을 주고, Worker는 interrupt 후에도 잠시 더 돌 수 있습니다(앞에서 본 로그).

==================================================================

**시스템 후처리는 이미 먼저 끝났습니다.** 맨 아래 `업무 후처리`는 **다른 스레드(Worker)** 가 늦게 찍은 로그입니다.

### 무슨 일인가

타임아웃 ON이면 스레드가 둘입니다.

| 스레드            | 역할                                                                   |
| ----------------- | ---------------------------------------------------------------------- |
| **요청 스레드**   | `Future.get(10000)` 초과 → `FW_TIMEOUT` → **시스템 후처리** → ImageLog |
| **Worker 스레드** | sleep/SQL을 **계속** 돌리다 끝나면 Service End → **업무 후처리**       |

로그 순서:

1. `23:49:50.446` — 시스템 후처리 종료 (`FW_TIMEOUT` 응답 조립) ← 요청 스레드
2. `23:49:50.450` — Worker가 SQL 실행 중
3. `23:49:50.451` — Service End / ImageLog에 TIMEOUT 기록
4. `23:49:50.454` — `BizPrePostAspect.after` (성공 DTO) ← **Worker가 뒤늦게 완료**

클라이언트에는 이미 TIMEOUT이 나갔고, Worker는 `cancel`/`interrupt` 후에도 sleep을 잡아서 넘기거나 SQL까지 가서 **정상 완료 로그**를 남긴 겁니다.

### 정리

- “시스템 후처리가 마지막이어야 한다”는 **한 스레드 정상 성공 경로** 기준입니다.
- TIMEOUT 경로는 **요청 스레드가 먼저 시스템 후처리로 응답**하고, Worker 로그가 **뒤에 섞여** 보일 수 있습니다.
- 이상 동작이 아니라 `OnlineTimeoutExecutor`의 알려진 특성(늦은 Worker 완료 / 커밋은 막되 실행 즉시 중단은 보장 안 함)입니다.

원하시면 Worker가 TIMEOUT 이후 `@AfterReturning`을 찍지 않게 막는 방안도 볼 수 있습니다.
