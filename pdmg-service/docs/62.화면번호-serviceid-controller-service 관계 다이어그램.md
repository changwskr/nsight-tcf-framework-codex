## 9. TCF ON/OFF 비교

```text
                       TCF ON
화면
  → Service ID
  → POST /online
  → OnlineTransactionController
  → TransactionDispatcher
  → Handler
  → Facade
  → Service
  → DAO
  → Mapper
  → DB


                       TCF OFF
화면
  → Service ID
  → POST /{Service ID}
  → 업무 Controller
  → Facade
  → Service
  → DAO
  → Mapper
  → DB
```

공통 업무 처리 부분:

```text
TCF ON  ──▶ Handler ──────┐
                          ▼
                       Facade
                          │
TCF OFF ──▶ Controller ───┘
                          │
                          ▼
                       Service
                          │
                          ▼
                         DAO
                          │
                          ▼
                        Mapper
                          │
                          ▼
                          DB
```

## 13. 최종 관계 공식

```text
화면번호
  = 프로그램 ID

Service ID
  = 화면번호 + 거래구분 + 순번

Controller
  = 화면번호 + Controller

Facade
  = 화면번호 + Facade

Service
  = 화면번호 + Service

DAO
  = 화면번호 + DAO

Mapper 파일
  = 화면번호 + "-" + DB구분 + ".xml"

Controller / Facade / Service 메서드
  = Service ID

DAO / Mapper Statement ID
  = Service ID + "_" + SQL구분 + 순번
```

한 줄로 표현하면 다음과 같습니다.

```text
화면번호
 → Service ID
 → Controller 또는 Handler
 → Facade(@Transactional)
 → Service
 → DAO
 → Mapper XML
 → SQL
 → DB
 → DTOout
 → 화면
```
