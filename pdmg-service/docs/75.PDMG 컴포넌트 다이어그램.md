```text

   │

   ├─ PasswordEncoder
   └─ JwtTokenIssuer
          │
          ▼
      RSA Private Key
          │
          ▼
      RS256 Access Token
```

```text

   │
   ▼
RSA Public Key
   │
   ▼
JWKSet
   │
   ▼
JwkSetController
   │
   ▼
GET /.well-known/jwks.json
```
