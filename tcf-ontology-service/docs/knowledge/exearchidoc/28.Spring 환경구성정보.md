|------|-----|
| 앱 이름 | `pdmg` (`spring.application.name`) |
| 기본 프로파일 | **`local`** |

    │  nhnis.fw.timeout.enabled=true (5000ms)

## 1. 설정 파일 위치

| 모듈 | 경로 | 역할 |
|------|------|------|
| **pdmg-service** | `src/main/resources/application.yml` | **운영·로컬 실제 설정** (프로파일 문서 포함) |
| pdmg-service | `src/main/resources/exceptionCode.yml` | 오류 메시지 (`spring.config.import`) |
| pdmg-service | `src/main/resources/log4j2.xml` | 로그 경로·레벨 |

| pdmg-fw | `src/main/resources/exceptionCode.yml` | FW 공통 코드 (서비스 yml과 병합·오버라이드 가능) |

`@ConfigurationPropertiesScan("nhnis")` 로 `nhnis.*` 바인딩 클래스를 스캔한다.

## 2. 프로파일

| 프로파일 | 활성 방식 | JWT | 비고 |
|----------|-----------|-----|------|
| **local** (기본) | `spring.profiles.active: local` | `jwt.enabled: false` · Filter에서 토큰 검증 **생략** | 개발 PC |
| **dev** | `--spring.profiles.active=dev` | `jwt.enabled: false` | access-token 만료 240000ms |
| (비-local) | 운영 등 | Filter가 JWT 검증 | `PDMG_JWT_SECRET` 권장 |

`DefaultFilter`는 `spring.profiles.active`가 **`local`이 아니면** JWT·헤더 엄격 검증을 탄다.  
앱 `SecurityConfig`는 `permitAll` — **인증 강제점은 DefaultFilter**다.

## 3. 핵심 스위치 (`nhnis.fw.*`)

`pdmg-service` `application.yml` 현행 값:

| 키 | 현행 | 효과 |
|----|------|------|
| `nhnis.fw.tcf.enabled` | **`true`** | `OnlineTransactionController` · `TcfFacade` · `GlobalExceptionHandler` 활성 |
| `nhnis.fw.timeout.enabled` | **`true`** | `DefaultOnlineTimeoutExecutor` (Worker+TX) |
| `nhnis.fw.timeout.milliseconds` | **`5000`** | 온라인 Dispatcher~DAO 공통 SLA |
| `nhnis.fw.timeout.pool-size` | **`20`** | Worker 풀 |
| `nhnis.fw.timeout.queue-capacity` | **`100`** | 큐 포화 시 503 `FW_OVERLOADED` |
| `nhnis.fw.commons.filter.enabled` | **`true`** | `DefaultFilter` |
| `nhnis.fw.commons.legacy-web.enabled` | **`true`** | ImageLog 등 레거시 웹 보조 Aspect |

```yaml
nhnis:
  fw:
    tcf:
      enabled: true
    timeout:
      enabled: true
      milliseconds: 5000
      pool-size: 20
      queue-capacity: 100
    commons:
      legacy-web:
        enabled: true
      filter:
        enabled: true
```

| 끄면 | 동작 |
|------|------|
| `tcf.enabled=false` | 단일 OnlineController 비활성 → `application.controller` 호환 경로 |
| `timeout.enabled=false` (또는 누락) | `SyncOnlineTimeoutExecutor` — 동기, **제한 없음** |
| `filter.enabled=false` | `DefaultFilter` 미등록 (Context/JWT 경로 깨짐 — 비권장) |

상세: [20.타임아웃.md](./20.타임아웃.md) · [16.TCF-OnlineTransactionController.md](./16.TCF-OnlineTransactionController.md)

## 4. 데이터소스 · SQL 초기화

### 4.1 로컬 (현행 활성)

| 항목 | 값 |
|------|-----|
| 접두 | `spring.datasource.rdw` → Bean `rdwDataSource` (Hikari, `@Primary`) |
| JDBC URL | `jdbc:log4jdbc:h2:mem:pdmg;MODE=Oracle;DB_CLOSE_DELAY=-1;DB_CLOSE_ON_EXIT=FALSE` |
| Driver | `net.sf.log4jdbc.sql.jdbcapi.DriverSpy` |
| User | `sa` / (빈 비밀번호) |
| 초기화 | `spring.sql.init.mode=always` |
| Schema / Data | `classpath:db/h2/schema.sql`, `classpath:db/h2/data.sql` |
| 인코딩 | UTF-8 |

### 4.2 사내 Oracle (주석 전환)

`application.yml` 안에 원본 블록이 주석으로 있다. H2 블록을 끄고 아래를 살린다.

| 항목 | 원본 예 |
|------|---------|
| URL | `jdbc:log4jdbc:oracle:thin:@19.24.148.173:1521:SBMFCRT` |
| User | `MFCR` |
| Password | `${PDMG_RDW_PASSWORD:}` |
| sql.init | 보통 끔 (운영 스키마 사용) |

### 4.3 MyBatis · TX

| Bean | 출처 |
|------|------|
| `rdwSqlSessionFactory` / `rdwSqlSessionTemplate` | `nhnis.mg.co.a.config.RdwDataSourceConfig` |
| Mapper XML | `classpath*:rdw.*/*.xml` (예: `rdw.mg.co.a/`) |
| `@MapperScan` | `nhnis.mg.co.a.persistence.dao` |
| TM | **`rdwTransactionManager`** (`DataSourceTransactionManager`) |

OnlineTimeoutExecutor도 `@Qualifier("rdwTransactionManager")` 로 같은 TM을 쓴다.

## 5. JWT (프로파일별)

공통 키: `jwt.secret`, `jwt.enabled`, `jwt.access-token-expiration`

| 프로파일 | enabled | secret | access-token-expiration |
|----------|---------|--------|-------------------------|
| local | `false` | `${PDMG_JWT_SECRET:pdmg-local-dev-secret-key-change-me-32b}` | `180000` |
| dev | `false` | 동일 기본값 | `240000` |

- 소비: `nhnis.fw.commons.jwt.JwtProvider` (`@Value("${jwt.secret}")`)
- FW 샘플: `application-fw-defaults.yml` 의 `jwt.secret` — **앱 yml이 우선**
- 운영: 반드시 **`PDMG_JWT_SECRET`** 환경변수로 덮어쓸 것 (32자+ 권장)

## 6. CORS · MVC

pdmg-ui 브라우저가 `POST http://localhost:8080/{serviceId}` 를 **직접** 호출하므로 CORS가 필요하다.

```yaml
spring:
  mvc:
    cors:
      allowed-origins:
        - http://localhost:8090
        - http://127.0.0.1:8090
      allowed-methods: [GET, POST, OPTIONS]
      allowed-headers: ["*"]
```

| 클래스 | 역할 |
|--------|------|
| `CorsProperties` (`spring.mvc.cors`) | 바인딩 |
| `WebMvcConfig` | `/**` CORS + `CorsConfigurationSource` Bean |
| `SecurityConfig` | `.cors(Customizer.withDefaults())` |
| `DefaultFilter` | `OPTIONS` preflight는 `shouldNotFilter` |

`allowed-origins`가 비면 CORS 미등록.

## 8. 로그 (`log4j2.xml`)

| 용도 | 로컬 경로 | 사내 WAS (주석 원본) |
|------|-----------|----------------------|
| Framework | `logs/application/` | `/home/mfpobimx/.../application` |
| Service | `logs/service/` | `/home/mfpobimx/.../service` |

- 상대 경로는 **프로세스 CWD** 기준 (`bootRun` = 프로젝트 루트일 때 의도 위치).
- WAR/WAS는 **절대 경로**로 전환.
- MDC: `guid`, `userId`, `serviceId`, `ip` 등 (`CORE_HEADER` …).

## 9. pdmg-ui (참고)

| 키 | 현행 | 의미 |
|----|------|------|
| `server.port` | `8090` | UI |
| `pdmg.ui.target-base-url` | `http://localhost:8080` | 화면 초기 대상 URL |

## 11. 조건부 Bean 맵 (설정 → 코드)

| 설정 | 활성 컴포넌트 |
|------|----------------|
| `nhnis.fw.tcf.enabled=true` | `OnlineTransactionController`, `TcfFacade`, `TransactionDispatcher`, `GlobalExceptionHandler` |
| `nhnis.fw.timeout.enabled=true` | `DefaultOnlineTimeoutExecutor` + pool |
| `nhnis.fw.timeout.enabled≠true` | `SyncOnlineTimeoutExecutor` |
| `nhnis.fw.commons.filter.enabled=true` | `DefaultFilter` / `FilterConfiguration` |
| `nhnis.fw.commons.security.enabled=true` | FW `SecurityConfig` (앱에 별도 Security가 있으므로 보통 끔) |
| `nhnis.fw.commons.legacy-web.enabled` | `PdmgFwTxFlowAspect` 등 |
