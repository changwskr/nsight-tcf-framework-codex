# Ontology 1.0 API 호출 예시

기본 URL: `http://localhost:8098`  
기동: `cd tcf-ontology-service` → `gradlew.bat bootRun` (또는 `RUN.bat`)

정본 Query API는 `/api/ontology/query/**` 이다.  
`/api/ontology/v1/**` 는 호환용이다.

---

## 0. Health / 정합성

```bash
curl -s http://localhost:8098/health
curl -s http://localhost:8098/api/ontology/consistency
curl -s http://localhost:8098/api/ontology/catalog
```

`consistency.status=ALIGNED` 이면 YAML Hub와 Graph 건수가 일치한다.

---

## 1. ServiceId 분해

```bash
curl -s http://localhost:8098/api/ontology/v1/service-id/mgcoa8888S0
```

예상: `groupCode=mg`, `businessCode=co`, `functionCode=a`, `programNo=8888`, `operationType=S`, `sequence=0`, `programId=mgcoa8888`

---

## 2. 구조 조회 (핵심 — 테스트 A)

```bash
curl -s http://localhost:8098/api/ontology/query/service/mgcoa8888S0/structure
```

체인:

`MG → CO → A → mgcoa8888 → mgcoa8888S0 → Handler → Facade → Service → DAO → Mapper/SQL → Table`

호환:

```bash
curl -s http://localhost:8098/api/ontology/v1/chain/mgcoa8888S0
```

---

## 3. Program / Handler / Business

```bash
curl -s http://localhost:8098/api/ontology/query/program/mgcoa8888/services
curl -s http://localhost:8098/api/ontology/query/handler/mgcoa8888Handler/services
curl -s http://localhost:8098/api/ontology/query/business/CO/tree
```

## 4. Table 정·역방향

```bash
curl -s http://localhost:8098/api/ontology/query/service/mgcoa8888S0/tables
curl -s http://localhost:8098/api/ontology/query/table/TB_FW_IMAGE_LOG/services
curl -s http://localhost:8098/api/ontology/impact/table/TB_FW_IMAGE_LOG
```

---

## 5. RUNTIME TX 체인

```bash
curl -s http://localhost:8098/api/ontology/query/runtime/tx-chain
curl -s http://localhost:8098/api/ontology/runtime/tx-chain
```

DESIGN `CALLS`와 별개로 Filter → TimeoutExecutor → Dispatcher → … 파이프라인을 본다.

## 6. Architecture Rules

```bash
curl -s http://localhost:8098/api/ontology/validate/rules
```

---

## 7. Concept / Provenance

```bash
curl -s http://localhost:8098/api/ontology/v1/concept/mgcoa8888
curl -s http://localhost:8098/api/ontology/v1/concept/mgcoa8888S0
curl -s "http://localhost:8098/api/ontology/v1/concept/component:nhnis.mg.co.a.entry.handler.mgcoa8888Handler"
```

`outgoing` 중 `HANDLED_BY`의 `provenance`로 출처를 확인한다.

---

## 8. Hub(기존) API — Facade 통합

YAML 4축 + Graph가 함께 내려온다 (`sources`, `graph`).

```bash
curl -s http://localhost:8098/api/ontology/service/mgcoa8888S0
curl -s http://localhost:8098/api/ontology/program/mgcoa8888
curl -s "http://localhost:8098/api/ontology/path?system=MG&business=CO&function=A&program=mgcoa8888"
curl -s "http://localhost:8098/api/ontology/impact?from=TB_FW_IMAGE_LOG"
curl -s "http://localhost:8098/api/ontology/recommend?system=MG&business=CO&function=A&intent=crud"
curl -s http://localhost:8098/api/ontology/prompt/mgcoa8888
```
