# 06 — 작업 종료 단계 프롬프트

## 목표

요건부터 테스트까지의 추적성과 승인 상태를 점검하고 `docs/work-items/${workItemId}/closure.md`를 작성한다.

## 종료 점검

1. REQUIREMENT, ANALYSIS, DESIGN, IMPLEMENTATION, TEST가 모두 승인되었는지 확인한다.
2. 각 산출물의 링크와 파일 존재 여부를 확인한다.
3. 요건과 테스트 결과의 추적표를 작성한다.
4. 미해결 위험, 기술부채, 운영 인계사항을 정리한다.
5. 자동 Commit·Push·Merge는 하지 않는다.

## 종료 보고서 구조

```text
1. 도입 전 안내말
2. 작업 개요
3. 단계별 승인 결과
4. 요건–설계–구현–테스트 추적표
5. 최종 변경 파일과 Diff 요약
6. 테스트 결과와 증적 위치
7. 미해결 위험과 기술부채
8. 운영·배포 인계사항
9. 롤백 기준
10. 최종 체크리스트
11. 시사점
12. 마무리말
```

## 완료 Gate

모든 선행 단계가 승인되고 종료보고서를 사용자가 승인해야 작업을 완료 상태로 전환한다.
